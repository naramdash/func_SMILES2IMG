# SMILES2IMG 향후 개선 계획 (PLAN)

## 1. 개요 및 현재 상태
현재 C# 소스 코드 최적화 및 화학 구조 렌더링 스타일 개선을 완료한 상태입니다.
- **코드 단순화:** 복잡한 상태 추적 딕셔너리 및 중복 캐시를 제거하고, 숨김 시트 기반 단일 상태 관리 및 해시 조회 구조로 정리 (약 444줄 → 402줄, 신규 기능 포함).
- **화학 렌더링 개선:** 
  - 고정 900×600 캔버스 제거 ➡️ 결합 길이(80px), 여백(30px) 기반 가변 해상도 자동 크기 조절.
  - Kekulé 이중결합 표기(`dearomatize`), `aromaticity-model = generic`.
  - 골격식 표기(`render-label-mode = hetero`) 및 불필요한 `Chiral` 라벨 숨김.
  - **고리 접합부/가교 키랄 수소(H) 선별 보존:** 아플라톡신 접합부 쐐기 H 표시, α-투존 등 소형 고리 내부의 쐐기 결합 겹침 현상 방지.
  - **흑백(ACS 저널 스타일) 옵션 지원:** `=SMILES2IMG(A2, FALSE)` 또는 `=SMILES2IMG(A2, "bw")`.

## 2. 실사용 시트 분석 기반 개선 과제

### Task 1: `#VALUE!` 오류 현상 (해결/원인 확인 완료)
* **현상:** 오에난토톡신 2번째 행에서 `#VALUE!` 오류 발생.
* **원인 확인:** 엑셀의 **셀 병합(Merged Cells)**으로 인해 수식이 참조하는 셀 위치 불일치로 발생한 현상임 (SMILES 파싱 문제가 아니므로 별도 코드 수정 불필요).

---

### Task 2: 유황(S) 원자 색상 시인성 (확인 완료 / 수정 불필요)
* **현상:** 티아민(비타민 B1, Thiamine)의 티아졸 고리에 있는 유황(S) 원자 시인성 검토.
* **확인 결과:** 실제 렌더링 픽셀 분석 결과, 밝은 레몬 옐로우(#FFFF00)가 아닌 흰 배경 대비가 반영된 **황갈색/다크 골든로드(#A88013)**로 이미 정상 렌더링되고 있음을 확인 (별도 코드 수정 불필요).

---

### Task 3: 헤테로원자 결합 메틸기(N-Me, O-Me) 및 소형 분자 가독성 개선 (구현 완료)
* **현상:**
  - **니코틴/카페인:** 피롤리딘 질소(N)에 결합된 메틸기가 달랑 빗금 하나(`N-`)로 그려져 가독성 저하 (`N-CH₃` 선호).
  - **아플라톡신/베르게닌/피레트린:** 메톡시기(`-OCH₃`), 메틸 에스터(`-COOCH₃`)가 단순 빗금으로 끝나 혼동 유발.
  - **MIC / 메탄올:** 초소형 분자에서 메틸기가 빗금 하나(`\`)로 표시됨.
* **해결 및 구현 내용:**
  - **소형 분자 자동 분기:** 중원자 수 ≤ 4개인 소형 분자(MIC, 메탄올, 에탄올, 아세트산 등)는 `render-label-mode = terminal-hetero`를 자동 적용하여 `H₃C-N=C=O`, `H₃C-OH` 등 화학 표준 명시적 텍스트 표기.
  - **헤테로원자 결합 메틸기 자동 식별:** 분자 크기가 큰 경우에도 헤테로원자(N, O, S)에 결합된 말단 탄소를 자동 탐지하여 `CH₃` (좌측 결합 시 `H₃C`) 라벨을 부여함으로써 순수 탄소 골격(카로틴, 페로몬 등)의 깔끔함을 해치지 않으면서 치환기 시인성을 극대화.

### Task 4: 분자 2D 레이아웃 방향(Orientation) 및 회전/반전 지원 (구현 완료)
* **현상:**
  - SMILES는 연결 위상 그래프이므로 원자 번호 순서에 따라 고리계의 좌우 배치나 브릿지 각도가 교과서 손그림과 반대로 뒤집히거나 기울어질 수 있음 (예: 니코틴, 티아민).
* **해결 및 구현 내용:**
  - **스마트 수평 레이아웃 기본화:** `smart-layout = true` 및 `layout-orientation = horizontal`을 엔진 옵션에 기본 적용하여 고리 간 연결 결합을 수평으로 반듯하게 정렬하고, 가로가 긴 엑셀 셀 종횡비에 최적화.
  - **수식 옵션을 통한 정밀 회전/반전 제어 지원:** `=SMILES2IMG(smiles, [background], [color], [transform])` 지원.
    - 사용 예시:
      - `=SMILES2IMG(A2, , , "flip")` : 좌우 반전
      - `=SMILES2IMG(A2, , , "rot90")`, `"rot180"`, `"rot270"` : 90/180/270도 회전
      - `=SMILES2IMG(A2, , FALSE, "flip")` : 흑백 + 좌우 반전 동시 적용

### Task 5: 표준 화학 골격 템플릿(Scaffold Template) 및 배좌 검토 (분석 및 정리 완료)
* **현상:**
  - 글루코스(Glucose) 등 당류는 교과서의 의자형 배좌(Chair conformation) 대신 평면 쐐기형 육각형으로 렌더링됨.
* **분석 및 기술적 한계 정리:**
  - SMILES(`OC[C@@H](O1)...`)는 3D 좌표나 배좌 정보를 포함하지 않는 2D 위상 그래프입니다.
  - 화학 정보학(IUPAC 2D 그래픽 표현 권고안, Indigo, RDKit 등)에서 SMILES로부터 생성되는 표준 2D 표현형은 평면 육각 고리에 입체 중심을 쐐기/점선 결합으로 명시하는 방식입니다.
  - 의자형 배좌는 3D 공간적 배좌(Conformation)의 투시도이므로, 순수 SMILES 2D 레이아웃 알고리즘으로는 생성되지 않으며 별도의 좌표 템플릿 파일이 필요합니다.
  - 따라서 현재 엔진의 평면 쐐기 결합 표현이 화학적으로 가장 엄밀하고 왜곡 없는 2D 표준 표기법임을 확정하고, 고리 접합부 수소 및 스마트 레이아웃을 통해 최상의 2D 가독성을 확보하였습니다.

---

### Task 6: 배경색 유무 및 투명 배경(Transparent) 지원 (구현 완료)
* **현상:**
  - 셀에 채우기 색상(노란색, 회색 등)이 적용되어 있거나 줄무늬 서식이 있는 경우, 흰색 배경 박스로 인해 이질감이 발생할 수 있음.
* **해결 및 구현 내용:**
  - **투명 배경 옵션 지원:** `=SMILES2IMG(smiles, [background], [color], [transform])`에서 2번째 인자로 `"trans"`, `"transparent"` 지원.
  - **사용자 정의 배경색 지원:** `"white"`(기본값), `"#FFFF00"` 또는 `"bg=#F0F0F0"` 형태로 원하는 배경색 지정 가능.
  - **캐시 키 분리:** 배경 설정(`_BG_transparent`, `_BG_#ffff00` 등)에 따라 별도 캐시 키가 생성되어 수식 변경 시 즉각 반영.
  - **사용 예시:**
    - `=SMILES2IMG(A2, "trans")` : 컬러 + 투명 배경 (쉼표 건너뛰기 불필요)
    - `=SMILES2IMG(A2, "trans", FALSE)` : 흑백 + 투명 배경
    - `=SMILES2IMG(A2, "trans", FALSE, "flip")` : 흑백 + 투명 배경 + 좌우 반전
