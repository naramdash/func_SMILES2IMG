# Getting Started

Once **`func_SMILES2IMG`** is installed and the **`[SMILES]`** ribbon tab is visible, try rendering your first molecule in Excel, Word, or PowerPoint in under 1 minute.

## 1. Microsoft Excel — First Formula (`=NAME2IMG` / `=SMILES2IMG`)

Paste either formula below into any empty cell and press <kbd>Enter</kbd> (on **Excel 2016–2021**, append **`.FLOAT`**, e.g. `=NAME2IMG.FLOAT("Aspirin")`):

```text
=NAME2IMG("Aspirin")
```
```text
=SMILES2IMG("CN1C=NC2=C1C(=O)N(C(=O)N2C)C")
```

Increase the row height (e.g. `62–80 pt`) and column width—the structure scales automatically with its aspect ratio locked. **Double-click** any structure cell to edit it in the built-in Ketcher 2D sketcher.

## 2. Microsoft Word — Insert & Re-Edit in Place

1. Place your cursor in prose or inside a compound summary table.
2. Click **`[SMILES]` ➔ `[Insert / Edit Structure]`** (or press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>).
3. Sketch your molecule or reaction in Ketcher and press <kbd>Ctrl</kbd> + <kbd>Enter</kbd> to insert inline. **Double-click** it anytime later to modify in place without breaking table column widths.

## 3. Microsoft PowerPoint — Dark Mode & 3D Slides

Insert alpha-transparent white-ink structures onto dark presentation templates, convert textboxes containing SMILES/names in 0.1s with **`[Paste Structure]`**, or embed 360°-rotatable 3D protein models via **`[3D Structure (Mol*)]`**.
