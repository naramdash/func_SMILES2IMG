## 🔄 2. 원클릭 작업 흐름 (4-Step Workflow)

<p align="center">
  <img src="../assets/workflow-ketcher.png" alt="4-Step Workflow" width="100%" />
</p>

| 단계 | 수행 작업 | 상세 설명 |
| :---: | :--- | :--- |
| **STEP 1** | **에디터 호출** | • 분자를 넣을 슬라이드를 선택합니다.<br>• PowerPoint 상단 리본 메뉴에서 **`[SMILES]`** ➔ **`[🧬 분자 구조식 삽입]`**을 클릭합니다. |
| **STEP 2** | **2D 스케치** | • 팝업된 Ketcher 에디터에서 마우스로 자유롭게 구조를 스케치합니다.<br>• 또는 외부에서 복사한 SMILES 문자열이나 MOL 파일을 불러옵니다. |
| **STEP 3** | **슬라이드에 즉시 배치** | • 우측 상단 녹색 **`[슬라이드에 적용 (Apply)]`** 버튼을 누릅니다.<br>• 현재 슬라이드 정중앙에 고해상도 벡터급 분자 도형이 즉시 삽입됩니다! |
| **STEP 4** | **더블 클릭 재편집** | • 발표 준비 중 구조를 수정해야 할 때는 해당 분자 도형을 **더블 클릭**!<br>• 기존 구조식이 그대로 열리며, 수정 후 [적용]을 누르면 **슬라이드 상의 기존 위치, 중심점, 크기를 완벽하게 유지하며 자동 갱신**됩니다. |

## 🎨 3. 내장 Ketcher 에디터 화면 가이드

<p align="center">
  <img src="../assets/ketcher-guide.png" alt="Ketcher Editor Interface" width="100%" />
</p>

### 주요 조작 팁
* **정밀한 입체 배치**: 회전, 반전, 입체 결합(Wedge/Hash) 도구를 활용하여 프로젝터 화면에서 한눈에 들어오는 가독성 높은 구조식을 그릴 수 있습니다.
* **무손실 화학 데이터 보존**: 슬라이드에 삽입된 모든 그림의 개체 속성(`대체 텍스트`, `제목`, `태그`)에 원본 SMILES 정보가 보존되므로, 나중에 언제든 원본 화학 구조를 복원할 수 있습니다.
* **100% 로컬 오프라인 보안**: PC 내부 가상 호스트(`ketcher.local`)에서 완전 오프라인으로 구동되므로, **연구소 내부 기밀 슬라이드도 보안 유출 걱정 없이 안전하게 작성**할 수 있습니다.

## 💡 5. 세련된 슬라이드 디자인 실전 팁

### 1) 현대적인 4분할 화합물 카드 레이아웃
상단 쇼케이스 이미지처럼 깔끔한 화합물 카드를 구성하면 전문적인 제약/화학 포스터 느낌을 줄 수 있습니다:
1. 연한 회색(`#F8FAFC`) 배경 슬라이드에 흰색 둥근 사각형 카드 4개를 배치합니다.
2. 카드 상단에 분자 구조식을 배치하고, 하단에 텍스트 상자로 화합물명, 화학식, 타겟 단백질 정보를 적습니다.
3. 분자 그림을 더블 클릭하여 수정하더라도 카드 영역을 벗어나지 않고 제자리를 지킵니다.

### 2) 다단계 화학 반응식 (Reaction Scheme) 작성
* 출발 물질(Reactant), 중간체(Intermediate), 최종 생성물(Product)을 각각 슬라이드에 삽입합니다.
* PowerPoint 기본 도형의 **[블록 화살표]**를 분자 사이에 배치하고, 화살표 위아래에 촉매, 온도, 용매 조건을 텍스트로 적어줍니다.
* 반응 경로 연구가 진행됨에 따라 중간체 분자를 더블 클릭하여 작용기를 즉시 업데이트할 수 있습니다.

### 3) 위치·비율 자동 보존의 마법 (Smart Aspect Ratio Preservation)
* 슬라이드에 삽입된 분자 그림을 원하는 크기로 자유롭게 늘리거나 줄일 수 있습니다.
* 이후 구조를 수정했을 때, 프로그램이 **이전 도형의 중심 좌표와 가로/세로 경계 상자를 분석하여 찌그러짐 없이 완벽한 비율로 새 분자를 정중앙에 배치**합니다.

### 4) PowerPoint 네이티브 애니메이션 적용
* 삽입된 분자는 일반 도형과 동일하므로 **[밝기 변화(Fade)]**, **[확대/축소(Zoom)]**, **[날아오기(Fly In)]** 등 파워포인트의 모든 애니메이션 효과를 그대로 적용할 수 있습니다.

## ❓ 6. 자주 묻는 질문 및 트러블슈팅

| 질문 / 증상 | 답변 및 해결 방법 |
| :--- | :--- |
| **Q. 발표장에 추가 기능이 없는 노트북으로 가도 슬라이드가 보이나요?** | **A. 네, 100% 완벽하게 표시됩니다.** 그림 자체가 파워포인트 슬라이드 파일(`.pptx`) 내부에 완전한 고해상도 그림으로 저장되므로, 빔프로젝터 연결 노트북, Mac, 아이패드, 웹용 PowerPoint 어디서든 고화질로 정상 발표하실 수 있습니다. |
| **Q. Word나 Excel의 분자 그림을 복사해서 붙여넣어도 되나요?** | **A. 네, 완벽 호환됩니다.** Excel이나 Word에서 만든 분자 그림을 복사하여 PowerPoint에 붙여넣어도 SMILES 화학 정보가 그대로 유지되며, 슬라이드에서도 더블 클릭으로 바로 수정할 수 있습니다. |
| **Q. 도형을 더블 클릭했는데 에디터 창이 안 떠요.** | **A.** 도형을 한 번 클릭하여 선택 상태로 만든 뒤, 상단 리본 메뉴의 **`[SMILES]` ➔ `[✏️ 구조식 편집]`** 버튼을 누르시면 즉시 에디터가 열립니다. |
| **Q. 슬라이드 배경이 어두운 다크 테마일 때는 어떻게 하나요?** | **A.** 어두운 슬라이드 배경에는 분자 그림 뒤에 연한 회색이나 흰색의 둥근 직사각형 '카드 도형'을 배경으로 깔아주시면 CPK 결합선이 극적인 대비를 이루며 가장 선명하게 돋보입니다. |
