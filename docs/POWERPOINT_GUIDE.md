학술대회 발표 슬라이드, 세미나, 연구 보고 발표, 투자 설명회(IR) PPT에 고해상도 2D 화학 구조식을 즉시 삽입하고, 마우스 더블 클릭으로 언제든 수정할 수 있는 PowerPoint 전용 화학 추가 기능입니다.

## 🔄 2. 원클릭 작업 흐름 (4-Step Workflow)

<p align="center">
  <img src="../assets/workflow-ketcher.png" alt="4-Step Workflow" width="100%" />
</p>

| 단계 | 수행 작업 | 상세 설명 |
| :---: | :--- | :--- |
| **STEP 1** | **에디터 호출** | • 분자를 넣을 슬라이드를 선택합니다.<br>• PowerPoint 상단 리본 메뉴에서 **`[SMILES]`** ➔ **`[🧬 분자 구조식 삽입]`**을 클릭합니다. |
| **STEP 2** | **2D 캔버스 스케치** | • 팝업된 Ketcher 에디터에서 분자, **반응 화살표(Reaction Arrow)**, **시약/촉매 조건 텍스트**를 자유롭게 배치합니다.<br>• 우측 상단 **`[배경: 투명 / 흰색]`** 버튼으로 슬라이드 테마에 맞는 배경을 선택합니다. |
| **STEP 3** | **슬라이드에 즉시 배치** | • 우측 상단 녹색 **`[슬라이드에 적용 (Ctrl+Enter)]`** 버튼을 누릅니다.<br>• 현재 슬라이드 정중앙에 고해상도 분자/반응식 도형이 즉시 삽입됩니다! |
| **STEP 4** | **더블 클릭 / 우클릭 재편집** | • 발표 준비 중 구조를 수정해야 할 때는 해당 분자 도형을 **더블 클릭**하거나 **마우스 우클릭 ➔ `[분자 구조식 편집]`**을 클릭!<br>• **KET 네이티브 캔버스 데이터**가 복원되며, 수정 후 [적용]을 누르면 **슬라이드 상의 기존 위치, 중심점, 크기를 완벽하게 유지하며 자동 갱신**됩니다. |

## 🎨 3. 내장 Ketcher 에디터 화면 가이드

<p align="center">
  <img src="../assets/ketcher-guide.png" alt="Ketcher Editor Interface" width="100%" />
</p>

### 주요 조작 팁
* **단축키 및 빠른 적용**: 에디터에서 스케치를 마친 후 <kbd>Ctrl</kbd> + <kbd>Enter</kbd>를 누르면 즉시 슬라이드에 반영됩니다.
* **배경 투명 / 흰색 전환**: 상단 헤더의 **`[배경: 투명]`** 버튼을 클릭하면 **`[배경: 흰색]`**으로 전환되어 다크 테마 슬라이드에서도 별도의 배경 도형 없이 깔끔하게 삽입할 수 있습니다.
* **무손실 KET 캔버스 보존**: 슬라이드에 삽입된 모든 도형의 태그(`KET_DATA`, `SMILES_DATA`) 및 대체 텍스트에 원본 KET 캔버스와 SMILES 정보가 보존되므로, 화살표·텍스트·배치까지 완벽히 재편집할 수 있습니다.
* **100% 로컬 오프라인 보안**: PC 내부 가상 호스트(`ketcher.local`)에서 완전 오프라인으로 구동되므로, **연구소 내부 기밀 슬라이드도 보안 유출 걱정 없이 안전하게 작성**할 수 있습니다.

## 🛠️ 4. PowerPoint 상단 리본 메뉴 및 우클릭 컨텍스트 메뉴

<p align="center">
  <img src="../assets/ribbon-guide.png" alt="Ribbon Guide" width="100%" />
</p>

### 상단 `[SMILES]` 리본 탭
| 버튼 아이콘 | 기능 이름 | 용도 및 설명 |
| :---: | :--- | :--- |
| 🧬 | **분자 구조식 삽입** | 활성 슬라이드 중앙에 새 분자/반응식 캔버스를 그리는 Ketcher 창을 엽니다. |
| ✏️ | **구조식 편집** | 슬라이드에서 선택한 분자 도형의 원본 KET/SMILES 정보를 불러와 수정합니다. (더블 클릭과 동일) |
| ⚡ | **클립보드 즉시 삽입** | 클립보드에 복사된 SMILES / MOL / KET 텍스트를 에디터 창을 열지 않고 슬라이드 중앙에 즉시 고해상도 이미지로 삽입합니다. |
| 📋 | **SMILES 복사** | 선택한 분자 도형에 내장된 정규 SMILES 문자열을 클립보드로 복사합니다. |
| 🧪 | **분자 정보 복사** | 선택한 분자 도형의 **화학식(Formula)**, **분자량(MW)**, **정밀 질량(Exact Mass)**, **SMILES**를 자동 계산하여 팝업으로 보여주고 클립보드에 복사합니다. |

### 마우스 오른쪽 클릭 (Context Menu)
* **분자 그림 / 도형 우클릭**:
  * `분자 구조식 편집 (Ketcher)...`
  * `SMILES 복사 (추출)`
  * `분자 정보 (화학식·분자량) 복사`
  * `캔버스 데이터(KET) 복사`

## 💡 5. 세련된 슬라이드 디자인 실전 팁

### 1) 현대적인 4분할 화합물 카드 레이아웃
상단 쇼케이스 이미지처럼 깔끔한 화합물 카드를 구성하면 전문적인 제약/화학 포스터 느낌을 줄 수 있습니다:
1. 연한 회색(`#F8FAFC`) 배경 슬라이드에 흰색 둥근 사각형 카드 4개를 배치합니다.
2. 카드 상단에 분자 구조식을 배치하고, 하단에 텍스트 상자로 화합물명, 화학식, 타겟 단백질 정보를 적습니다.
3. 분자 그림을 더블 클릭하여 수정하더라도 카드 영역을 벗어나지 않고 제자리를 지킵니다.

### 2) 다단계 화학 반응식 (Reaction Scheme) 작성
* 출발 물질(Reactant), 중간체(Intermediate), 최종 생성물(Product)을 각각 슬라이드에 삽입하거나, Ketcher 캔버스 하나에 반응 화살표와 함께 통째로 작성하여 삽입할 수 있습니다.
* 반응 경로 연구가 진행됨에 따라 분자 도형을 더블 클릭하여 작용기나 화살표 조건을 즉시 업데이트할 수 있습니다.

### 3) 위치·비율 자동 보존의 마법 (Smart Aspect Ratio Preservation)
* 슬라이드에 삽입된 분자 그림을 원하는 크기로 자유롭게 늘리거나 줄일 수 있습니다.
* 이후 구조를 수정했을 때, 프로그램이 **이전 도형의 중심 좌표와 가로/세로 경계 상자를 분석하여 찌그러짐 없이 완벽한 비율로 새 분자를 정중앙에 배치**합니다.

### 4) PowerPoint 네이티브 애니메이션 적용
* 삽입된 분자는 일반 도형과 동일하므로 **[밝기 변화(Fade)]**, **[확대/축소(Zoom)]**, **[날아오기(Fly In)]** 등 파워포인트의 모든 애니메이션 효과를 그대로 적용할 수 있습니다.

## ❓ 6. 자주 묻는 질문 및 트러블슈팅

| 질문 / 증상 | 답변 및 해결 방법 |
| :--- | :--- |
| **Q. 발표장에 추가 기능이 없는 노트북으로 가도 슬라이드가 보이나요?** | **A. 네, 100% 완벽하게 표시됩니다.** 그림 자체가 파워포인트 슬라이드 파일(`.pptx`) 내부에 완전한 고해상도 그림으로 저장되므로, 빔프로젝터 연결 노트북, Mac, 아이패드, 웹용 PowerPoint 어디서든 고화질로 정상 발표하실 수 있습니다. |
| **Q. Word나 Excel의 분자 그림을 복사해서 붙여넣어도 되나요?** | **A. 네, 완벽 호환됩니다.** Excel이나 Word에서 만든 분자 그림을 복사하여 PowerPoint에 붙여넣어도 KET 캔버스 및 SMILES 화학 정보가 그대로 유지되며, 슬라이드에서도 더블 클릭으로 바로 수정할 수 있습니다. |
| **Q. 도형을 더블 클릭했는데 에디터 창이 안 떠요.** | **A.** 도형을 마우스 우클릭하여 **`[분자 구조식 편집 (Ketcher)...]`**를 선택하거나, 상단 리본 메뉴의 **`[SMILES]` ➔ `[✏️ 구조식 편집]`** 버튼을 누르시면 즉시 에디터가 열립니다. |
| **Q. 슬라이드 배경이 어두운 다크 테마일 때는 어떻게 하나요?** | **A.** Ketcher 에디터 상단 헤더의 **`[배경: 투명]`** 버튼을 클릭하여 **`[배경: 흰색]`**으로 토글한 뒤 적용하시거나, 분자 그림 뒤에 흰색의 둥근 직사각형 '카드 도형'을 배경으로 깔아주시면 CPK 결합선이 극적인 대비를 이루며 가장 선명하게 돋보입니다. |
