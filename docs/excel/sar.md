# Substructure & Similarity (SAR)

Filter compound libraries by functional group or scaffold (`=SMILES.MATCH`), highlight matching atoms directly inside rendered structures (`hl:`), and rank analogs by 2D fingerprint similarity (`=SMILES.SIMILARITY`).

```text
=SMILES.MATCH(A2, "c1ccccc1")
=SMILES.SIMILARITY(A2, $B$2)
=SMILES2IMG(A2, "", "hl:c1ccccc1")
```

## Similarity Metrics & Combined `IF` Filtering

* `=SMILES.SIMILARITY(mol1, mol2, [metric])` supports `"tanimoto"` (default), `"tversky"`, and `"euclid-sub"`, returning a numeric score from `0.0` to `1.0`.
* Combine with Lipinski screening directly in Excel:

```text
=IF(AND(SMILES2LIPINSKI(A2)="PASS", SMILES.MATCH(A2, "c1ccncc1")), "Priority Hit", "Exclude")
```
