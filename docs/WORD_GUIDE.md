## 🔄 2. 원클릭 작업 흐름 (4-Step Workflow)

<p align="center">
  <img src="../assets/workflow-ketcher.png" alt="4-Step Workflow" width="100%" />
</p>

| 단계 | 수행 작업 | 상세 설명 |
| :---: | :--- | :--- |
| **STEP 1** | **에디터 호출** | • 본문 또는 표의 원하는 셀에 커서를 위치시킵니다.<br>• Word 상단 리본 메뉴에서 **`[SMILES]`** ➔ **`[🧬 분자 구조식 삽입]`**을 클릭합니다. |
| **STEP 2** | **2D 캔버스 스케치** | • 팝업된 Ketcher 에디터에서 분자, **반응 화살표(Reaction Arrow)**, **시약/반응 조건 텍스트**를 자유롭게 배치합니다.<br>• 우측 상단 **`[배경: 투명 / 흰색]`** 버튼으로 그림 배경을 선택할 수 있습니다. |
| **STEP 3** | **문서에 즉시 삽입** | • 우측 상단 녹색 **`[문서에 적용 (Ctrl+Enter)]`** 버튼을 누릅니다.<br>• 커서 위치에 고해상도 인라인 그림(`InlineShape`)이 즉시 삽입됩니다! |
| **STEP 4** | **더블 클릭 / 우클릭 재편집** | • 수정이 필요할 때는 해당 그림을 **더블 클릭**하거나 **마우스 우클릭 ➔ `[분자 구조식 편집]`**을 선택합니다.<br>• **KET 네이티브 캔버스 데이터**가 그대로 복원되어 화살표·텍스트·배치까지 완벽히 이어서 편집할 수 있습니다. |

## 🎨 3. 내장 Ketcher 에디터 화면 가이드

<p align="center">
  <img src="../assets/ketcher-guide.png" alt="Ketcher Editor Interface" width="100%" />
</p>

### 주요 조작 팁
* **단축키 및 빠른 적용**: 에디터에서 작업을 마친 후 <kbd>Ctrl</kbd> + <kbd>Enter</kbd>를 누르면 즉시 문서에 적용됩니다.
* **배경 투명 / 흰색 전환**: 상단 헤더의 **`[배경: 투명]`** 버튼을 클릭하면 **`[배경: 흰색]`**으로 토글되어 어두운 표 셀이나 배경 위에서도 선명한 이미지를 얻을 수 있습니다.
* **무손실 KET 캔버스 보존**: 삽입된 그림의 Word 개체 속성에 Ketcher 네이티브 포맷(`KET:...`)과 `SMILES:...`가 함께 기록되어, 2D 좌표·반응 화살표·텍스트가 유실 없이 보존됩니다.
* **100% 로컬 오프라인 보안**: PC 내부 가상 호스트(`ketcher.local`)에서 완전 오프라인으로 구동되므로, **외부 유출이 금지된 제약·바이오·배터리 미공개 R&D 화합물도 안심하고 작성**할 수 있습니다.

## 🛠️ 4. Word 상단 리본 메뉴 및 우클릭 컨텍스트 메뉴

<p align="center">
  <img src="../assets/ribbon-guide.png" alt="Ribbon Guide" width="100%" />
</p>

### 상단 `[SMILES]` 리본 탭
| 버튼 아이콘 | 기능 이름 | 용도 및 설명 |
| :---: | :--- | :--- |
| 🧬 | **분자 구조식 삽입** | 현재 커서가 위치한 본문이나 표의 셀 안에 새 분자/반응식 캔버스를 그리는 Ketcher 창을 엽니다. |
| ✏️ | **구조식 편집** | 선택한 분자 그림의 원본 KET/SMILES 데이터를 불러와 수정합니다. (더블 클릭과 동일) |
| ⚡ | **클립보드 즉시 삽입** | 본문에서 드래그로 선택한 SMILES 텍스트 또는 클립보드에 복사된 SMILES/MOL/KET 데이터를 에디터 창 없이 즉시 고해상도 그림으로 변환해 삽입합니다. |
| 📋 | **SMILES 복사** | 선택한 분자 그림에 내장된 정규 SMILES 문자열을 클립보드로 추출합니다. |
| 🧪 | **분자 정보 복사** | 선택한 분자의 **화학식(Formula)**, **분자량(MW)**, **정밀 질량(Exact Mass)**, **SMILES**를 자동 계산하여 팝업으로 보여주고 클립보드에 복사합니다. |

### 마우스 오른쪽 클릭 (Context Menu)
* **분자 그림 / 도형 우클릭**:
  * `분자 구조식 편집 (Ketcher)...`
  * `SMILES 복사 (추출)`
  * `분자 정보 (화학식·분자량) 복사`
  * `캔버스 데이터(KET) 복사`
* **본문 텍스트 우클릭**:
  * `분자 구조식 삽입 (Ketcher)...`

## 📋 5. 실전 문서 작성 및 서식 레이아웃 팁

### 1) 화학 보고서 및 논문 표(Table) 완벽 서식 만들기
Word 표에 분자 구조식을 삽입할 때 아래와 같이 배치하면 세계적인 저널(ACS, RSC) 수준의 깔끔한 양식을 만들 수 있습니다:

| 화합물명 | 화학식 / 용도 | 2D 화학 구조식 | SMILES 코드 |
| :--- | :--- | :---: | :--- |
| **Aspirin (아스피린)** | C₉H₈O₄<br>NSAID 진통소염제 | *(더블 클릭 시 Ketcher 열림)* | `CC(=O)Oc1ccccc1C(=O)O` |
| **Caffeine (카페인)** | C₈H₁₀N₄O₂<br>크산틴 알칼로이드 | *(더블 클릭 시 Ketcher 열림)* | `Cn1cnc2c1c(=O)n(C)c(=O)n2C` |

> [!TIP]
> **표 정렬 추천:**  
> 분자 구조식이 들어가는 열은 표 도구 레이아웃에서 **`가운데 맞춤(Align Center)`**으로 설정하면 결합선과 글자가 표 셀 중앙에 아름답게 정렬됩니다.

### 2) 그림 크기 조절 및 종횡비 유지
* 삽입된 그림의 모서리 조절점을 마우스로 드래그하여 원하는 크기로 자유롭게 조절할 수 있습니다.
* 이후 마우스 더블 클릭으로 구조를 수정하더라도, **사용자가 설정해 둔 너비와 높이를 프로그램이 기억하여 찌그러짐 없이 자동 비례 조절**합니다.

### 3) 고해상도 인쇄 및 PDF 전자 문서 내보내기
* 본 추가 기능의 모든 이미지는 안티앨리어싱(Anti-Aliasing)이 적용된 고해상도 그래픽으로 생성됩니다.
* Word에서 **[파일] ➔ [내보내기] ➔ [PDF/XPS 만들기]**를 실행해도 분자의 미세 결합선이 번짐 없이 벡터급 선명도를 유지합니다.

## ❓ 6. 자주 묻는 질문 및 트러블슈팅

| 질문 / 증상 | 답변 및 해결 방법 |
| :--- | :--- |
| **Q. 추가 기능이 없는 동료에게 워드 문서(.docx)를 보내면 어떻게 보이나요?** | **A. 완벽하게 정상 표시됩니다.** 그림 자체가 워드 파일 내부에 포함되어 저장되므로, Mac이나 모바일, 추가 기능이 없는 PC에서도 선명한 화학식 그림이 그대로 보입니다. 또한 그 동료가 나중에 추가 기능을 설치하면 그 그림을 더블 클릭하여 바로 편집할 수도 있습니다. |
| **Q. Word와 PowerPoint 간에 복사-붙여넣기가 되나요?** | **A. 네, 100% 호환됩니다.** Word 본문의 분자 그림을 복사(`Ctrl+C`)해서 PowerPoint 슬라이드에 붙여넣기(`Ctrl+V`)해도 화학 SMILES 메타데이터가 그대로 유지되므로, 슬라이드에서도 더블 클릭으로 바로 수정할 수 있습니다. |
| **Q. 더블 클릭을 했는데 아무 반응이 없어요.** | **A.** 그림을 마우스로 가볍게 한 번 클릭한 뒤, 상단 리본 메뉴 **`[SMILES]` ➔ `[✏️ 구조식 편집]`** 버튼을 눌러보세요. |
| **Q. 인터넷이 안 되는 실험실 PC에서도 작동하나요?** | **A. 네, 100% 오프라인으로 작동합니다.** Indigo 화학 C++ 엔진과 Ketcher 에디터 파일이 로컬 드라이브에 설치되어 구동되므로 인터넷 연결이 전혀 필요 없습니다. |
