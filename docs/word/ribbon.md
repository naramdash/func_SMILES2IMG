# Ribbon & Context Menu

Reference for every command on the Microsoft Word **`[SMILES]`** ribbon tab and 3-level **`Chemical Structure`** right-click menu.

<FeatureMedia id="word-ribbon-tools" />

## Top `[SMILES]` Ribbon Commands

| Group | Command | Action |
| :--- | :--- | :--- |
| **Insert Structure** | `Insert / Edit Structure` (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>) | Open Ketcher 2D to insert inline or re-edit the selected structure |
| | `3D Structure (Mol*)` | Open Mol\* 3D viewer to insert rotatable `.glb` models or 2D `.png` figures |
| | `Paste Structure` | Convert selected SMILES text or clipboard chemical data into an inline figure in 0.1s |
| **Structure Tools** | `Copy SMILES` / `Copy InChI` / `Copy KET` / `Copy SVG` | Extract identifiers or copy lossless vector SVG from the selected figure |
| | `Molecule Info` | View all 17 properties or copy TSV, Summary, Multi-Line, Markdown, or JSON |
| | `Batch Style` | Restyle selected structures or the entire manuscript in one click |
| **About** | `About func_SMILES2IMG` | Check installed version, third-party notices, and updates |
