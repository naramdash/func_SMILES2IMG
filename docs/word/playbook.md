# Word Playbook

Explore a complete 6-page self-contained Microsoft Word manuscript packed with live double-click-editable chemical structures, a fixed-width journal SAR table, KET synthesis schemes, a Mol\* 3D protein figure, and a 1-click ACS B&W submission exercise.

<PlaybookPreview app="word" />

::: tip How to Use This Playbook
1. Make sure **`func_SMILES2IMG`** is installed ([Installation](/guide/install)).
2. Download <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_Word_Playbook.docx" download="func_SMILES2IMG_Word_Playbook.docx"><strong>func_SMILES2IMG_Word_Playbook.docx (.docx)</strong></a> and open it directly in **Microsoft Word**.
3. Follow the embedded exercise boxes—select plain SMILES/name text and click **`[Paste Structure]`**, **double-click** any 2D reaction or 3D `1CRN` protein figure to reopen **Ketcher 2D** / **Mol\* 3D**, or test 1-click **`[Batch Style]` ➔ `[Publication B&W]`** across the entire manuscript.
:::

## Page-by-Page Breakdown (6 Pages)

| Page / Chapter | Contents & Built-In Hands-On Exercises |
| :--- | :--- |
| **Page 1 · Orientation & Reference** | Cover guide + complete Word `[SMILES]` Ribbon & 3-level `Chemical Structure` context menu table |
| **Page 2 · Ch. 1 Inline & 0.1s Convert** | Live double-click-editable Aspirin & Caffeine inline figures + selectable SMILES/Name/InChI 0.1s **`[Paste Structure]`** exercise box |
| **Page 3 · Ch. 2 Journal SAR Table** | Fixed-column-width 6-column manuscript table (4 live structures + descriptors) + **`[Molecule Info]`** zero-typo copy exercise |
| **Page 4 · Ch. 3 Synthesis Schemes (KET)** | Aspirin & Paracetamol multi-step reaction schemes with embedded KET metadata + in-place Ketcher catalyst editing exercise |
| **Page 5 · Ch. 4 3D Protein Target (Mol\*)** | Transparent Crambin (`PDB: 1CRN`) figure (double-click to reopen Mol\* 3D) + `2D PNG` / `3D GLB` / offline `.pdb` comparison table |
| **Page 6 · Ch. 5 ACS B&W, SVG & Fixes** | 1-click document-wide **`[Batch Style]` ➔ `[Publication B&W]`** exercise, Vector SVG copy guide & offline troubleshooting table |
