# Word Playbook (`.docx`)

Practice inline 2D structures, `0.1s` text conversion, fixed-width SAR compound tables, lossless `KET` reaction schemes, `Mol*` 3D protein figures, and 1-click ACS B&W journal restyling inside a self-contained 6-page manuscript—without keeping web docs open alongside Word.

<PlaybookPreview app="word" />

::: tip Recommended Two-Step Setup
1. **Install `func_SMILES2IMG` first** ([10-Second Install Guide](/guide/install)) so the **`[SMILES]`** ribbon tab and double-click editors are active when you open the document.
2. Download <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_Word_Playbook.docx" download="func_SMILES2IMG_Word_Playbook.docx"><strong>func_SMILES2IMG_Word_Playbook.docx (.docx)</strong></a> and open it in **Microsoft Word**.
3. Work through the green callouts on Pages 1–6 (takes ~5 minutes): highlight text strings and click **`[Paste Structure]`**, **double-click** any embedded structure, KET reaction, or `1CRN` 3D protein to edit in place, and run **`[Batch Style]` ➔ `[Publication B&W]`** across the manuscript.
:::
