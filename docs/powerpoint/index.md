## Slide Workflows

| Slide Task | Guide | Ribbon Command |
| :--- | :--- | :--- |
| Build dark-theme candidate cards & white-ink structures | [Dark Mode & Screening Cards](/powerpoint/dark-mode) | `[Batch Style]` ➔ `[Dark Mode]` |
| Convert a slide TextBox SMILES or name in 0.1s | [TextBox Quick Convert](/powerpoint/quick-convert) | `[Paste Structure]` |
| Draw editable multi-step reaction mechanisms | [Reaction Mechanism Slides](/powerpoint/reactions) | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> (`[Insert / Edit Structure]`) |
| Embed 360°-rotatable 3D protein models | [3D Protein Slides (Mol*)](/powerpoint/3d-proteins) | `[3D Structure (Mol*)]` |
| Look up or paste bulleted properties during Q&A | [Live Q&A Molecule Info](/powerpoint/molecule-info) | `[Molecule Info]` |
| Restyle an entire deck or copy A0 poster SVG | [Deck-Wide Batch Style & SVG](/powerpoint/batch-style) | `[Batch Style]` & `[Copy SVG]` |
