# 4. A0 Posters (SVG), Q&A, Podium Sharing

Run this 5-minute pre-conference checklist to ensure razor-sharp **A0 / A1 poster graphics**, effortless **live Q&A chemistry answers**, and glitch-free playback on any **conference podium PC or Mac**.

## 5-Minute Conference & Poster Checklist

### Step 1: Copy Infinite-Resolution Vector `SVG` for A0 / A1 Posters (`Copy SVG`)

Standard PNG or JPG captures look fine on a laptop screen, then turn jagged and blurry when printed at **A0 / A1 poster dimensions (90 × 120 cm)** at 300 DPI.

1. Click any 2D molecule or `KET` reaction pathway on a slide (or highlight a SMILES/name text string inside a TextBox).
2. Click **`[SMILES]` ➔ `[Copy SVG]`** (or right-click ➔ **`Chemical Structure` ➔ `Copy Vector SVG`**).
3. Paste (<kbd>Ctrl</kbd> + <kbd>V</kbd>) onto your PowerPoint A0 poster canvas (Office 365 / 2019+) or into **Adobe Illustrator / Inkscape**—every bond path, wedge, and atom letter pastes as crisp infinite-resolution vector paths ready to scale to meter-wide banners.

### Step 2: Prepare Live Q&A Chemistry Metrics (`Molecule Info`)

In full-screen Slide Show mode, PowerPoint hides the Ribbon and right-click add-in menus. Use this realistic two-step Q&A workflow instead:

* **Before Stepping on Stage (Zero-Switch Prep):** For key candidates, select each structure shape ➔ click **`[SMILES]` ➔ `[Molecule Info]` ➔ `[Copy as Multi-Line List]`**, and paste Formula, Exact Mass, LogP, TPSA, and `Fsp3` straight into **Speaker Notes** (visible only to you in Presenter View).
* **During Deep-Dive Q&A / Group Meetings:** Press <kbd>Esc</kbd> to return to Normal view, click the structure (or highlight any SMILES/name text), and open **`[Molecule Info]` ➔ `[Detailed Molecule Info Window...]`** to display all 12 descriptors with a clean 2D preview—double-click any row to copy a single number. *(See [Style & Export Reference](/editor/publishing) for all 5 copy formats.)*

### Step 3: Verify Podium PC, macOS & PDF Handouts

* **Podium PC / macOS Playback:** Both 2D PNGs and 3D `.glb` models (including **Morph** camera transitions) are native PowerPoint shapes embedded inside `.pptx`, so they run cleanly on any conference podium PC or **macOS** machine without `func_SMILES2IMG` installed.
* **Lightweight PDF / Legacy PowerPoint Handouts:**
  * Converting `.pptx` to PDF flattens 3D `.glb` shapes at their resting camera angle—make sure each 3D slide rests at a clear view before exporting.
  * For printed monochrome handouts, save a duplicate copy and run **`[SMILES]` ➔ `[Batch Style]` ➔ `[Publication B&W]`** in 1 click.
