# PowerPoint Playbook (`.pptx`)

Practice dark-mode chemical slide design directly inside Microsoft PowerPoint with the official 8-slide deck—including a live `0.1s` TextBox conversion sandbox, a 4-card lead candidate grid, a double-clickable `KET` reaction mechanism, a `Mol*` 3D protein slide, Q&A `Molecule Info` lookups, and step-by-step speaker notes.

<PlaybookPreview app="ppt" />

::: tip Recommended Two-Step Setup
1. **Install `func_SMILES2IMG` first** ([10-Second Install Guide](/guide/install)) so the **`[SMILES]`** ribbon tab and double-click editors are active when you open the deck.
2. Download <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_PowerPoint_Playbook.pptx" download="func_SMILES2IMG_PowerPoint_Playbook.pptx"><strong>func_SMILES2IMG_PowerPoint_Playbook.pptx (.pptx)</strong></a> and open it in **Microsoft PowerPoint** with the **Notes** pane visible.
3. Select the practice textboxes on Slide 3 and click **`[Paste Structure]`**, **double-click** the dark-mode Caffeine or KET reaction on Slides 1 & 5 to reopen **Ketcher 2D**, and test 1-click deck-wide theme switching via **`[Batch Style]`**.
:::
