# PowerPoint Playbook

Practice dark-mode chemistry slide design directly inside Microsoft PowerPoint with an 8-slide self-contained deck—complete with a 0.1s TextBox conversion lab, 4-card lead screening grid, editable KET mechanism slide, Mol\* 3D protein target, Q&A `Molecule Info`, and step-by-step speaker notes.

<PlaybookPreview app="ppt" />

::: tip How to Use This Playbook
1. Make sure **`func_SMILES2IMG`** is installed ([Installation](/guide/install)).
2. Download <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_PowerPoint_Playbook.pptx" download="func_SMILES2IMG_PowerPoint_Playbook.pptx"><strong>func_SMILES2IMG_PowerPoint_Playbook.pptx (.pptx)</strong></a> and open it directly in **Microsoft PowerPoint** with Speaker Notes visible.
3. Try the hands-on slides—select the plain text boxes on Slide 3 and click **`[Paste Structure]`**, **double-click** the dark-mode Caffeine or KET reaction scheme to edit in **Ketcher 2D**, or run 1-click **`[Batch Style]`** across the entire deck.
:::

## Slide-by-Slide Breakdown (8 Slides)

| Slide | Contents & Speaker-Note Walkthroughs |
| :--- | :--- |
| **Slide 1 · Cover & Roadmap** | Dark-slate executive cover with live double-click-editable dark-mode Caffeine structure + 3-stage deck roadmap |
| **Slide 2 · Ribbon & Menu Cheat Sheet** | Full PowerPoint `[SMILES]` Ribbon & 3-level context menu reference on a single slide |
| **Slide 3 · 0.1s TextBox Lab** | Three selectable plain-text boxes (SMILES, Name, Chiral SMILES) to convert live via **`[Paste Structure]`** beside expected dark-mode output |
| **Slide 4 · 4-Card Candidate Grid** | Transparent white-ink dark-mode screening cards (Aspirin, Caffeine, Nicotine, Paracetamol) with zero white rectangles |
| **Slide 5 · Reaction Pathway (KET)** | Aspirin acetylation reaction scheme inside a clean figure card with lossless KET `Shape.Tags` |
| **Slide 6 · 3D Protein Target (Mol\*)** | Crambin (`PDB: 1CRN`) 3D target slide + 3-step `3D Model (GLB)` Morph & transparent `2D Picture` workflow |
| **Slide 7 · Q&A Info & Batch Style** | Live conference Q&A **`[Molecule Info]`** multi-line bullet preview + 1-click deck-wide **`[Batch Style]`** exercise |
| **Slide 8 · Delivery & Support** | Sharing `.pptx` to macOS/venue PCs, A0 conference poster Vector SVG workflow & built-in troubleshooting checklist |
