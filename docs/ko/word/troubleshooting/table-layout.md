# 표 그림 잘림 · 일괄 스타일 범위

Word 본문이나 화합물 표 안에서 인라인 구조식의 윗부분이 잘려 보일 때, 수정 후 열 너비가 밀릴 때, 또는 `Batch Style` 이 원하는 범위와 다르게 적용될 때의 해결 방법입니다.

## 1. 표 셀이나 문단에서 구조식 위쪽이 잘려 보임 {#table-layout}

인라인 그림(`InlineShape`)의 아랫부분만 보이고 고리 위쪽이 앞 줄에 묻혀 깎여 보일 때:

* **원인:** 해당 문단이나 표 스타일의 **줄 간격**이 **`고정값`** (예: *고정값 12 pt*)으로 고정되어 있어 그림 높이가 글자 행 높이에 맞춰 잘려 표시됩니다.
* **해결 방법:** 문제되는 문단이나 표 열을 드래그 선택한 뒤 **홈 ➔ 단락 ➔ 줄 간격 옵션**에서 줄 간격을 **`1줄`** 또는 **`배수`(`1.15`)** 로 변경하세요. 변경 즉시 전체 구조식이 잘림 없이 펼쳐집니다.

## 2. 더블클릭 수정 후 표 열 너비가 틀어짐

* **구조식 삽입 전 표 너비 고정:** 표 우클릭 ➔ **자동 맞춤 ➔ 열 너비 고정**을 켜 두세요. `func_SMILES2IMG` 는 가로세로 비율(`LockAspectRatio`)을 고정해 기존 셀 너비 안에서 크기를 맞춰 교체합니다.
* **음영 셀 · 교대 줄 배경과 대비가 낮을 때:** **`[SMILES]` ➔ `[Batch Style]` ➔ `[Standard Color (Transparent)]`** 로 흰 사각형 여백을 없애거나, 짙은 음영 행 위에서는 **`[White Background (Color)]`** 를 적용해 뚜렷하게 분리하세요.

## 3. `Batch Style` 적용 범위가 예상과 다름 {#batch-style}

`Batch Style` 은 현재 Word에서 무엇이 선택되어 있는지에 따라 적용 범위를 자동으로 판별합니다:

* **특정 그림이나 표 영역을 드래그 선택한 경우:** 선택한 영역 내부의 2D 구조식만 변환합니다.
* **아무 그림도 선택하지 않고 본문에 커서만 둔 경우:** **Word 문서 전체(`.docx`)** 의 모든 2D 분자·`KET` 반응식을 일괄 변환합니다 (`Mol*` 3D 단백질 그림은 컬러 보존을 위해 자동 제외).

::: tip 실행 전 선택 상태 확인
문서 전체를 흑백 변환하려 했는데 그림 1개만 바뀌었다면, 그림 선택을 해제하고 빈 문단에 커서만 둔 뒤 **`[Batch Style]`** 을 다시 클릭하세요.
:::
