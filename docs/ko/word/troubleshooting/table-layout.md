# 표 레이아웃 · 스타일

Word 화합물 요약 표 안에서의 구조식 크기 유지와 원클릭 **`Batch Style`** 적용 범위 안내입니다.

## 1. 화합물 표의 열 너비 틀어짐 방지

* 표 셀 안의 인라인 구조식을 더블클릭해 교체할 때 `func_SMILES2IMG`는 가로세로 비율 고정(`LockAspectRatio`)을 유지하며 제자리 교체합니다.
* **다중 행 표 권장 설정:** 표 우클릭 ➔ **자동 맞춤** ➔ **열 너비 고정**을 켜 두면 긴 반응식을 넣을 때도 Word가 인접 텍스트 열을 임의로 좁히지 않습니다.

## 2. `Batch Style`이 일부만 바뀌거나 문서 전체가 바뀔 때

`Batch Style`은 현재 Word의 선택 영역(블록 지정)에 따라 적용 범위가 달라집니다:

* **일부 영역을 드래그 선택한 경우:** **`[SMILES]` ➔ `[Batch Style]`** 실행 시 **선택한 문단·표 안의 구조식만** 변환됩니다.
* **선택 없이 커서만 둔 경우:** **문서 전체의 모든 화학 구조식**을 한 번에 변환합니다(학술지 투고 직전 **`Publication B&W`** 일괄 적용에 최적).

## 3. 대형 포스터나 벡터 편집이 필요할 때

Word에는 인쇄용 고해상도 PNG가 삽입됩니다. Adobe Illustrator나 Inkscape에서 선 굵기·레이아웃을 직접 편집하려면 구조식을 선택하고 **`[SMILES]` ➔ `[Copy SVG]`** (또는 우클릭 ➔ **`Chemical Structure` ➔ `Copy Vector SVG`**)를 사용하세요.
