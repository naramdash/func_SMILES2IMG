# 더블클릭 편집 · 3D 단백질

Word 본문·표 안의 2D 구조식을 레이아웃 깨짐 없이 제자리에서 수정하거나, **Mol\* 3D**로 3D 단백질 모델과 고해상도 2D 그림을 삽입합니다.

<FeatureMedia id="word-ch5-edit-and-molstar" />

## 1. 더블클릭 제자리 2D 편집

* 본문이나 표 셀 안의 구조식 그림을 **더블클릭**하면 `0.05초` 이내에 Ketcher 2D가 다시 열립니다.
* 수정 후 적용하면 가로세로 비율 고정(`LockAspectRatio = msoTrue`)을 유지한 채 제자리 교체되어 표 열 너비와 문단 배치가 틀어지지 않습니다.

## 2. 3D 단백질 그림 삽입 (`Mol*`)

1. 상단 리본에서 **`[SMILES]` ➔ `[3D Structure (Mol*)]`** 버튼을 클릭합니다.
2. 4자리 PDB 코드(예: `1CRN`, `6LU7`)를 입력해 **`Fetch`** 버튼을 누르거나 로컬 `.pdb` / `.cif` 파일을 엽니다.
3. Cartoon · Surface · Ball & Stick 스타일을 조정한 뒤 삽입 방식을 고릅니다:
   - **`3D Model (GLB)`** — Word 안에서 360° 회전 가능한 대화형 3D 모델
   - **`2D Picture`** — 논문용 고해상도 `.png` 그림 (흰색 / 투명 / 다크 배경 선택)
4. 삽입된 3D 모델·2D 그림을 나중에 더블클릭하면 같은 카메라 각도 그대로 Mol\*이 다시 열립니다.
