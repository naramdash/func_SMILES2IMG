# Word 실습 원고 (Playbook `.docx`)

웹 문서를 함께 띄워 두지 않아도 Microsoft Word 안에서 더블클릭 편집 가능한 인라인 구조식, `0.1초` 텍스트 변환 실습 박스, 논문용 SAR 화합물 표, 무손실 KET 합성 반응식, Mol\* 3D 단백질 그림, 원클릭 ACS 흑백 변환까지 5분 안에 직접 실습할 수 있는 6페이지 공식 원고입니다.

<PlaybookPreview app="word" />

::: tip 권장 실습 순서 (설치 먼저 ➔ Playbook 열기)
1. **먼저 `func_SMILES2IMG`를 설치하세요** ([10초 설치 가이드](/ko/guide/install)) — 상단 `[SMILES]` 탭이 로드된 상태여야 파일 안의 실습 버튼과 더블클릭 편집기가 작동합니다.
2. <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_Word_Playbook.docx" download="func_SMILES2IMG_Word_Playbook.docx"><strong>func_SMILES2IMG_Word_Playbook.docx (.docx)</strong></a>를 내려받아 **Microsoft Word**에서 엽니다.
3. 1~6쪽의 초록색 실습 안내를 따라 SMILES·물질명 텍스트를 드래그해 **`[Paste Structure]`** 로 변환하고, 2D 반응식과 `1CRN` 3D 단백질 그림을 **더블클릭**으로 수정한 뒤, 문서 전체 **`[Batch Style]` ➔ `[Publication B&W]`** 전환까지 체험해 보세요.
:::

## 페이지별 상세 구성 (6페이지)

| 페이지 / 챕터 | 수록 내용 및 내장 실습 | 관련 가이드 |
| :--- | :--- | :--- |
| **1쪽 · 개요 & 리본 사전** | 사용 안내 + Word `[SMILES]` 리본 및 3단계 `Chemical Structure` 우클릭 메뉴 전체 참조표 | [리본 · 우클릭 메뉴](/ko/word/reference) |
| **2쪽 · Ch. 1 인라인 & 0.1초 변환** | 더블클릭 편집 가능한 아스피린·카페인 인라인 구조식 + 드래그 후 **`[Paste Structure]`** 실습 박스(SMILES·화합물명·InChI) | [1. 2D 구조식 · 반응식 작성](/ko/word/structures) |
| **3쪽 · Ch. 2 논문용 SAR 표** | 열 너비 고정 6열 화합물 요약 표(구조식 4종 + 물성) + **`[Molecule Info]`** 오타 없는 물성 복사 실습 | [2. 화합물 표(SAR) & 실험 물성(SI)](/ko/word/tables-properties) |
| **4쪽 · Ch. 3 합성 반응식 (KET)** | KET 메타데이터가 담긴 아스피린·파라세타몰 다단계 반응식 + 더블클릭 촉매 조건 추가 실습 | [1. 2D 구조식 · 반응식 작성](/ko/word/structures) |
| **5쪽 · Ch. 4 3D 단백질 (`Mol*`)** | 투명 배경 크람빈(`PDB: 1CRN`) 그림(더블클릭 시 Mol\* 3D 재오픈) + `2D Picture` / `3D Model (GLB)` / 오프라인 `.pdb` 비교표 | [3. 3D 단백질 Figure (Mol*)](/ko/word/3d-figures) |
| **6쪽 · Ch. 5 ACS 흑백 · SVG · 해결** | 원클릭 문서 전체 **`[Batch Style]` ➔ `[Publication B&W]`** 실습, 벡터 SVG 복사 안내 및 오프라인 트러블슈팅 표 | [4. 투고 마감 · 벡터 SVG · 공동저자 공유](/ko/word/publishing) |
