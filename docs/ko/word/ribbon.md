# 리본 · 우클릭 메뉴

Microsoft Word 상단 **`[SMILES]`** 리본 탭과 3단계 **`Chemical Structure`** 우클릭 컨텍스트 메뉴 레퍼런스입니다.

<FeatureMedia id="word-ribbon-tools" />

## 상단 `[SMILES]` 리본 명령

| 그룹 | 명령 | 기능 |
| :--- | :--- | :--- |
| **Insert Structure** | `Insert / Edit Structure` (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>) | Ketcher 2D를 열어 인라인 삽입 또는 선택 구조식 재편집 |
| | `3D Structure (Mol*)` | Mol\* 3D 뷰어로 회전 `.glb` 모델 또는 2D `.png` 그림 삽입 |
| | `Paste Structure` | 선택한 SMILES 텍스트 또는 클립보드 화학 데이터를 0.1초 만에 인라인 구조식으로 변환 |
| **Structure Tools** | `Copy SMILES` / `Copy InChI` / `Copy KET` / `Copy SVG` | 선택한 구조식에서 식별자 또는 무손실 벡터 SVG 복사 |
| | `Molecule Info` | 17종 물성 확인 및 TSV · 요약 · 목록 · 마크다운 · JSON 복사 |
| | `Batch Style` | 선택 영역 또는 문서 전체 구조식 스타일 원클릭 통일 |
| **About** | `About func_SMILES2IMG` | 설치된 버전, 서드파티 라이선스 확인 및 업데이트 체크 |
