# ACS 흑백 변환 · SVG

ACS, Wiley, Elsevier, RSC 등 학술지 투고 전 문서 전체의 구조식을 클릭 한 번으로 흑백 통일하거나, Adobe Illustrator용 무손실 벡터 SVG로 복사합니다.

<FeatureMedia id="word-ch6-publication-finish" />

## 1. 논문 전체 스타일 일괄 변환 (`Batch Style`)

1. 특정 문단·표만 변환하려면 해당 영역을 드래그 선택하고, **문서 전체**를 통일하려면 선택 없이 커서만 둡니다.
2. **`[SMILES]` ➔ `[Batch Style]`** 메뉴에서 원하는 프리셋을 클릭합니다:
   - **`Publication B&W`** — 학술지 투고·특허용 순수 흑백 선화
   - **`Standard Color`** — 투명 배경 + IUPAC 표준 원소 컬러
   - **`White Background`** — 불투명 흰색 배경 (음영이 들어간 표 셀에 적합)
   - **`Dark Mode`** — 투명 배경 + 흰색 선화

## 2. 무손실 벡터 SVG 복사 (`Copy SVG`)

Word에서 구조식을 선택한 뒤 **`[SMILES]` ➔ `[Copy SVG]`** (또는 우클릭 ➔ **`Chemical Structure` ➔ `Copy Vector SVG`**)를 누르고 Adobe Illustrator·Inkscape에 <kbd>Ctrl</kbd> + <kbd>V</kbd>로 바로 붙여넣습니다. 자세한 출력 옵션은 [스타일 & 출력](/ko/editor/publishing)을 참고하세요.
