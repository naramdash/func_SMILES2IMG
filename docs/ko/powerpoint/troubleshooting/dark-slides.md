# 다크 슬라이드 배경

어두운 PowerPoint 템플릿 위에 하얀 네모 배경이 생기거나 검은 선이 잘 보이지 않을 때의 해결 방법입니다.

## 1. 클릭 한 번으로 하얀 네모 배경 제거하기

흰 배경으로 삽입된 구조식을 다크 테마 슬라이드에 맞게 바꾸려면:

1. 슬라이드에서 해당 구조식을 선택합니다(아무것도 선택하지 않으면 **프레젠테이션 전체의 모든 화학 구조식**에 적용됩니다).
2. PowerPoint 상단 리본에서 **`[SMILES]` ➔ `[Batch Style]` ➔ `[Dark Mode]`** 메뉴를 클릭합니다.
3. 모든 대상 구조식이 즉시 **투명 배경 + 선명한 흰색 선화**로 변환됩니다.

## 2. Ketcher · Mol\*에서 처음부터 투명 배경으로 삽입하기

* **Ketcher 2D:** <kbd>Ctrl</kbd> + <kbd>Enter</kbd>로 적용하기 전 상단 바를 **`[Background: Transparent]`** 상태로 전환하세요.
* **Mol\* 3D (2D 그림 모드):** **`Apply to Slide`** 클릭 전 상단 툴바의 **`BG: Transparent`** 옵션을 선택하면 그라데이션 슬라이드 위에도 자연스럽게 올라갑니다.

## 3. 밝은 테마 슬라이드로 되돌리기

추후 밝은 발표 템플릿에 슬라이드를 재사용할 때는 **`[SMILES]` ➔ `[Batch Style]` ➔ `[Standard Color]`** (투명 배경 + 표준 컬러) 또는 **`[Publication B&W]`** (투명 배경 + 순수 흑백)를 클릭하면 됩니다.
