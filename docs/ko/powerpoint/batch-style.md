# 전체 슬라이드 스타일 · SVG

발표 자료 전체의 구조식을 클릭 한 번으로 다크 모드, 표준 컬러, 논문용 흑백, 흰색 배경으로 일괄 전환하거나, A0 학회 포스터용 무손실 벡터 SVG를 복사합니다.

<FeatureMedia id="powerpoint-slide-batch-style" />

## 1. 선택 도형 또는 발표 자료 전체 변환 (`Batch Style`)

1. 특정 슬라이드의 일부 도형만 바꾸려면 해당 도형을 선택하고, **프레젠테이션 전체**를 바꾸려면 아무것도 선택하지 않습니다.
2. **`[SMILES]` ➔ `[Batch Style]`** 메뉴에서 **`Standard Color`**, **`Publication B&W`**, **`White Background`**, **`Dark Mode`** 중 원하는 스타일을 클릭합니다.

## 2. 우클릭 메뉴 & 학회 포스터용 벡터 SVG

![PowerPoint 3단계 Chemical Structure 우클릭 메뉴](/powerpoint-context-menu-guide.png)

* 슬라이드 구조식 우클릭 ➔ **`Chemical Structure` ➔ `Copy Vector SVG`** 메뉴로 복사하면 Adobe Illustrator, Inkscape, 대형 A0 포스터에 깨짐 없이 바로 붙여넣을 수 있습니다.
* **`[SMILES]` ➔ `[About func_SMILES2IMG]`** 창에서 설치된 버전과 업데이트를 언제든 확인할 수 있습니다.
