# 다크 모드 · 후보 물질 카드

어두운 PowerPoint 발표 템플릿 위에 하얀 네모 여백 없이 투명한 흰색 선화 구조식을 깔끔하게 배치합니다.

## 1. 다크 테마 4종 후보 물질 비교 카드 그리드

<FeatureMedia id="powerpoint-slide-candidate-grid" />

1. 슬라이드 배경을 짙은 네이비·슬레이트(`#0F172A`)로 설정하고 화합물 카드를 배치합니다.
2. **`[SMILES]` ➔ `[Paste Structure]`** 또는 **`[Insert / Edit Structure]`** 버튼으로 각 후보 물질을 삽입합니다.
3. **`[SMILES]` ➔ `[Batch Style]` ➔ `[Dark Mode]`** 메뉴를 클릭하면 모든 구조식이 투명 배경의 흰색 결합선으로 즉시 통일됩니다.

## 2. 투명 흰색 선화 캔버스

<FeatureMedia id="powerpoint-slide-dark-mode" />

* **Ketcher 내부 설정:** **`Apply to Slide`** 버튼을 누르기 전 상단 바에서 **`[Background: Transparent]`** 옵션을 선택하세요.
* **언제든 일괄 전환:** 특정 도형만 선택하거나(선택 없으면 **발표 자료 전체**) **`[Batch Style]` ➔ `[Dark Mode]`** 메뉴를 실행합니다.
