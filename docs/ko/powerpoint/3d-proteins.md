# 3. 360° 3D 단백질 발표 (`Mol*` & 모핑)

내장 **Mol\*** 3D 뷰어로 PowerPoint 슬라이드 쇼 발표 도중 **마우스로 360° 돌려볼 수 있는 3D 단백질 모델(`.glb`)** 이나 투명 배경 고해상도 2D 그림을 삽입하고, **모핑(Morph)** 전환으로 시네마틱 3D 결합 포켓 줌인 애니메이션을 만듭니다.

<FeatureMedia id="powerpoint-slide-molstar-3d" />

## 1. 360° 회전 3D 모델 또는 투명 2D 그림 삽입

1. 구조식을 넣을 슬라이드로 이동합니다.
   ::: tip 숨은 꿀팁: 슬라이드 텍스트 상자의 PDB 코드 바로 불러오기
   슬라이드 텍스트 상자에 `1CRN`이나 `6LU7` 같은 4자리 PDB 코드(또는 로컬 `.pdb`/`.cif` 경로)가 적혀 있다면 **텍스트 상자를 선택한 상태에서 `[3D Structure (Mol*)]`를 클릭**하세요. Mol\*이 해당 단백질을 자동으로 즉시 로드합니다.
   :::
2. 상단 리본 **`[SMILES]` ➔ `[3D Structure (Mol*)]`** (또는 우클릭 ➔ **`Chemical Structure` ➔ `3D Structure (Mol*)...`**)를 클릭합니다.
3. 4자리 PDB 코드(`1CRN`, `4HHB`, `6LU7`, `1BNA`) 입력 후 **`Fetch`** 를 누르거나, **`Open File...`** 로 내 PC의 `.pdb`, `.cif`, `.bcif`, `.ent`, `.mol`, `.sdf`, `.molj`, `.molx` 파일을 오프라인으로 엽니다.
4. **Cartoon**, **Surface**, **Ball & Stick** 결합 포켓 스타일을 맞춘 뒤 상단 툴바에서 출력 모드를 고르고 <kbd>Ctrl</kbd> + <kbd>Enter</kbd> (**`Apply to Slide`**)를 누릅니다:

| Mol\* 출력 모드 | 슬라이드 동작 특징 | 추천 용도 |
| :--- | :--- | :--- |
| **`3D Model (GLB)`** | 편집 화면과 **슬라이드 쇼 발표 도중 마우스로 드래그해 360° 회전·확대**할 수 있는 네이티브 3D 개체 | 학회 구두 발표, 타깃-리간드 결합 포켓 라이브 시연 (PowerPoint 2019 / 2021 / 2024 / 365 지원) |
| **`2D Picture`** | 고해상도 `.png` 렌더링 삽입 (**`BG: Transparent`** 선택 시 다크·그라데이션 슬라이드에 자연스럽게 융화) | 초대형 단백질 복합체(파일 용량 절감), PDF 유인물, 구버전 PowerPoint 2016 호환 |

5. **카메라 각도 보존 재편집:** 슬라이드에 넣은 3D 모델이나 2D 단백질 그림을 일반 편집 화면에서 **더블클릭**하면 `CustomXMLParts`에 저장된 마지막 카메라 앵글과 스타일 설정 그대로 Mol\*이 다시 열립니다.

## 2. 발표 킬러 연출: PowerPoint `모핑(Morph)` & 내장 3D 애니메이션

`Mol*` 가 삽입하는 개체는 PowerPoint 표준 네이티브 **3D 모델(`.glb`)** 이므로, 무거운 동영상 인코딩이나 코덱 오류 걱정 없이 PowerPoint 자체 기능만으로 3D 단백질을 움직일 수 있습니다:

### A. 슬라이드 전환 3D 줌인 (`전환 ➔ 모핑`)
1. 첫 번째 슬라이드에 **`3D Model (GLB)`** 을 삽입하고 **단백질 전체 3차 구조(Cartoon)** 가 보이도록 각도를 맞춥니다.
2. 좌측 슬라이드 썸네일에서 해당 슬라이드를 **우클릭 ➔ 슬라이드 복제**합니다.
3. 복제된 두 번째 슬라이드에서 3D 모델을 마우스로 회전·확대해 **리간드 결합 포켓(Binding Pocket)** 을 클로즈업하고 설명 박스를 둘 여백에 맞춰 위치를 옮깁니다.
4. 두 번째 슬라이드를 선택한 채 PowerPoint 상단 **[전환(Transitions)] ➔ [모핑(Morph)]** 효과를 선택하면 발표 중 슬라이드를 넘길 때 3D 단백질이 부드럽게 회전·이동하며 확대됩니다.

### B. 한 슬라이드 안에서 계속 움직이는 3D 효과 (`애니메이션 ➔ 3D 애니메이션`)
슬라이드의 `.glb` 단백질을 클릭한 뒤 PowerPoint **[애니메이션(Animations)]** 탭을 열면 전용 3D 모션이 나타납니다:
* **`회전판(Turntable)`:** 전체 구조나 도메인 배치를 설명하는 동안 단백질이 제자리에서 360° 천천히 자전합니다.
* **`스윙(Swing)`:** 결합 포켓 정면을 가리지 않고 좌우로 살짝만 흔들어 주며 입체감과 깊이감을 강조합니다.
* **`도착(Arrive)`:** 슬라이드 등장 시 입체적으로 회전하며 안착합니다. **효과 옵션**에서 회전 방향, 강도, 반복 재생 여부를 자유롭게 조절하세요.

## 3. 파일 용량 관리 & 발표장 PC · Mac 호환성

* **추가 기능 없는 발표장 PC · Mac에서 100% 재생:** 삽입된 3D `.glb` 모델과 2D `.png` 그림은 PowerPoint 표준 내장 개체이므로, `func_SMILES2IMG`가 없는 **학회장 연단 PC나 macOS**에서도 3D 회전과 모핑 전환이 그대로 작동합니다.
* **초대형 복합체 용량 팁:** `1CRN`, `4HHB`, `6LU7` 같은 중소형 단백질은 `.glb`로 넣어도 매우 가볍고 빠릅니다. 수만 개 이상의 원자가 포함된 거대 리보솜·바이러스 캡시드이거나 이메일 첨부 용량 제한이 엄격할 때는 **`2D Picture`** + **`BG: Transparent`** 모드가 훨씬 쾌적합니다.
