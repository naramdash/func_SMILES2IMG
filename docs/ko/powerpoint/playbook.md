# PowerPoint 예제 파일 (Playbook)

다크 모드 화학 발표 슬라이드 제작을 Microsoft PowerPoint 안에서 직접 실습할 수 있는 8슬라이드 공식 덱입니다. 0.1초 텍스트 상자 변환 실습, 4카드 후보물질 그리드, 더블클릭 편집 KET 반응 메커니즘, Mol\* 3D 단백질 타깃, Q&A `Molecule Info` 및 단계별 발표자 노트가 모두 수록되어 있습니다.

<PlaybookPreview app="ppt" />

::: tip 활용 방법
1. 먼저 `func_SMILES2IMG`를 설치합니다 ([설치 가이드](/ko/guide/install)).
2. <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_PowerPoint_Playbook.pptx" download="func_SMILES2IMG_PowerPoint_Playbook.pptx"><strong>func_SMILES2IMG_PowerPoint_Playbook.pptx (.pptx)</strong></a>를 내려받아 발표자 노트를 켠 상태로 **Microsoft PowerPoint**에서 엽니다.
3. 슬라이드 3의 텍스트 상자를 선택해 **`[Paste Structure]`**로 즉시 변환하거나, 다크 모드 카페인·KET 반응식을 **더블클릭**해 **Ketcher 2D**로 편집하고, 원클릭 **`[Batch Style]`**로 덱 전체 테마를 전환해 보세요.
:::

## 슬라이드별 상세 구성 (8슬라이드)

| 슬라이드 | 수록 내용 및 발표자 노트 안내 |
| :--- | :--- |
| **Slide 1 · 커버 & 로드맵** | 더블클릭 편집 가능한 다크 모드 카페인 구조식이 포함된 다크 슬레이트 표지 + 3단계 학습 로드맵 |
| **Slide 2 · 리본 & 메뉴 치트시트** | PowerPoint `[SMILES]` 리본 및 3단계 우클릭 메뉴 전체 요약표 |
| **Slide 3 · 0.1초 텍스트 상자 실습** | 직접 선택해 **`[Paste Structure]`** 버튼으로 변환해 볼 수 있는 3개 텍스트 상자(SMILES·화합물명·카이랄)와 완성 결과 비교 |
| **Slide 4 · 4카드 후보물질 그리드** | 흰색 배경 테두리 없이 투명 흰색 결합선으로 정렬한 4종 후보물질(Aspirin·Caffeine·Nicotine·Paracetamol) 카드 |
| **Slide 5 · 합성 메커니즘 (KET)** | 무손실 KET `Shape.Tags`가 보존된 아스피린 아세틸화 반응식 슬라이드 |
| **Slide 6 · 3D 단백질 (Mol\*)** | 크람빈(`PDB: 1CRN`) 3D 타깃 슬라이드 + `3D Model (GLB)` 모핑(Morph)·투명 `2D Picture` 3단계 가이드 |
| **Slide 7 · Q&A 물성 & Batch Style** | 발표 질의응답용 **`[Molecule Info]`** 불릿 목록 미리보기 + 원클릭 덱 전체 **`[Batch Style]`** 전환 실습 |
| **Slide 8 · 공유 · 포스터 SVG · 해결** | macOS/발표장 PC 공유 안내, 대형 A0 포스터 벡터 SVG 복사 및 오프라인 트러블슈팅 체크리스트 |
