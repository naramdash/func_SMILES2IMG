# PowerPoint 실습 덱 (Playbook `.pptx`)

다크 모드 화학 발표 슬라이드 제작을 Microsoft PowerPoint 안에서 직접 실습할 수 있는 8슬라이드 공식 덱입니다. 텍스트 상자 변환 실습, 4카드 후보물질 그리드, 더블클릭 편집 KET 반응 메커니즘, Mol\* 3D 단백질 타깃, Q&A `Molecule Info` 및 단계별 발표자 노트가 수록되어 있습니다.

<PlaybookPreview app="ppt" />

::: tip 권장 실습 순서 (설치 먼저 ➔ 발표자 노트 켜고 열기)
1. **먼저 `func_SMILES2IMG`를 설치하세요** ([설치 가이드](/ko/guide/install)) — 상단 `[SMILES]` 탭이 로드된 상태여야 실습 버튼과 더블클릭 편집기가 작동합니다.
2. <a href="/func_SMILES2IMG/examples/func_SMILES2IMG_PowerPoint_Playbook.pptx" download="func_SMILES2IMG_PowerPoint_Playbook.pptx"><strong>func_SMILES2IMG_PowerPoint_Playbook.pptx (.pptx)</strong></a>를 내려받아 하단 **발표자 노트**를 켠 채 **Microsoft PowerPoint**에서 엽니다.
3. 슬라이드 3의 텍스트 상자를 선택해 **`[Paste Structure]`** 로 제자리 변환을 해 보고, 다크 모드 카페인·KET 반응식·`1CRN` 3D 그림을 **더블클릭**해 편집한 뒤, **`[Batch Style]`** 로 덱 전체 테마를 일괄 전환해 보세요.
:::

| **Slide 2 · 리본 & 메뉴 치트시트** | PowerPoint `[SMILES]` 리본 및 3단계 우클릭 메뉴 전체 요약표 | [리본 · 우클릭 메뉴](/ko/powerpoint/reference) |
| **Slide 3 · 텍스트 상자 변환 실습** | 직접 선택해 **`[Paste Structure]`** 버튼으로 제자리 변환해 볼 수 있는 3개 텍스트 상자(SMILES·화합물명·카이랄)와 완성 결과 비교 | [1. 2D 구조식 · 반응식 슬라이드](/ko/powerpoint/slides-structures) |
