# 텍스트 상자 즉시 변환

슬라이드에 입력한 SMILES 문자열이나 화합물 이름 텍스트 상자를 클릭 한 번으로 중앙 정렬·비율 고정된 2D 구조식으로 변환합니다.

<FeatureMedia id="powerpoint-slide-textbox-quick-insert" />

## 사용 순서

1. SMILES 문자열(예: `CC(=O)Oc1ccccc1C(=O)O`) 또는 화합물 이름(`Aspirin`)이 적힌 PowerPoint 텍스트 상자를 선택합니다.
2. 상단 리본에서 **`[SMILES]` ➔ `[Paste Structure]`** (또는 우클릭 ➔ **`Chemical Structure` ➔ `Paste Structure`**)를 클릭합니다.
3. 비율이 고정(`msoTrue`)된 선명한 2D 구조식이 슬라이드에 즉시 배치됩니다. *(선택된 텍스트 상자가 없으면 클립보드의 화학 텍스트를 변환해 삽입합니다.)*
