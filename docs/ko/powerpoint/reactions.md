# 반응 메커니즘 슬라이드

반응 화살표(`➔`), `+` 기호, 촉매·온도 주석이 포함된 다단계 합성 반응식을 PowerPoint 도형 메타데이터(`Shape.Tags["KET"]`)에 무손실 저장해 언제든 다시 편집할 수 있습니다.

<FeatureMedia id="powerpoint-slide-reaction" />

## 사용 순서

1. 상단 리본에서 **`[SMILES]` ➔ `[Insert / Edit Structure]`** (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>)를 클릭합니다.
2. **Ketcher 2D**에서 반응물, 화살표(`➔`), `+`, 시약·촉매 텍스트(`T`)를 그립니다.
3. <kbd>Ctrl</kbd> + <kbd>Enter</kbd>를 눌러 슬라이드에 배치합니다.
4. 추후 슬라이드 위의 반응식을 **더블클릭**하면 카드 배치가 틀어지지 않은 채 화살표와 조건을 제자리에서 수정할 수 있습니다.
