# 수식 오류 (`#NAME?`, `#VALUE!`, `#N/A`)

Microsoft Excel에서 `func_SMILES2IMG` 수식이 반환하는 오류·상태 코드별 원인과 해결 방법입니다.

## 1. `#NAME?` 오류

엑셀이 함수 이름을 인식하지 못할 때 나타납니다:

| 원인 | 확인 방법 | 해결 방법 |
| :--- | :--- | :--- |
| **Excel 2016 / 2019 / 2021** | 인셀 이미지 수식(`=SMILES2IMG`, `=NAME2IMG`, `=KET2IMG`, `=INCHI2IMG`)은 Microsoft 365 및 Excel 2024 이상 전용입니다. | 뒤에 `.FLOAT`를 붙이세요: `=SMILES2IMG.FLOAT(A2)`, `=NAME2IMG.FLOAT("Aspirin")` |
| **추가 기능 미로드 또는 차단** | `=SMILES2MW("CCO")`도 `#NAME?`이 뜨거나 `[SMILES]` 탭이 안 보입니다. | [설치 보안 차단](/ko/guide/troubleshooting/install) 및 [리본 탭 미표시](/ko/guide/troubleshooting/ribbon-tab)를 확인하세요. |

## 2. `#VALUE!` 오류

수식은 실행되었지만 입력값을 유효한 화학 구조로 파싱할 수 없을 때 나타납니다.

1. **빈 셀 또는 글자 수 제한 초과:** 비어 있거나 공백만 있는 셀, 그리고 **16,384자**를 넘는 입력은 `#VALUE!`를 반환합니다.
2. **화학 문법 · 원자가 · 포맷 확인:** 닫히지 않은 고리 번호(예: 끝 `1`이 빠진 `c1ccccc`), 괄호 불일치·빈 괄호(`CC(=O`), 잘못된 원자가(예: 중성 5가 탄소 `C(C)(C)(C)(C)C`), `INCHI2*`에 일반 SMILES 전달, `KET2*`에 일반 문자열 전달, `*.MATCH`의 잘못된 SMARTS 패턴을 점검하세요.
3. **병합된 셀:** 병합된 셀을 참조할 때는 반드시 **가장 왼쪽 위(좌상단) 셀**을 지정하세요.
4. **정확한 파서 오류 확인 (`Diagnostics`):** 리본 **`[SMILES]` ➔ `[Diagnostics]`** 메뉴를 클릭하면 오류가 발생한 수식 함수명과 EPAM Indigo 파서가 보고한 정확한 문법 오류 메시지(예: `SMILES2IMG: Indigo: ...`)를 확인할 수 있습니다.

## 3. `#N/A` 상태 표시 및 가드레일

* **잠시(~0.1초) 표시 후 자동 갱신:** 새 구조식을 처음 렌더링하거나 미캐시 이름을 PubChem에서 조회하는 동안 잠깐 `#N/A`가 떴다가 **완료 즉시 최종 이미지·값으로 자동 갱신**됩니다.
* **알 수 없는 이름 · 잘못된 CAS 체크 디지트:** 내장 사전이나 PubChem에 없는 이름(또는 미캐시 오프라인 상태)이거나 수학적 체크 디지트가 틀린 CAS 번호(예: `"50-78-3"`)를 `=NAME2*`에 넣으면 네트워크 대기 없이 즉시 `#N/A`를 반환합니다.
* **단일 분자 스칼라 함수의 쿼리 · 반응식 가드:** R-기(`*`, `[R1]`)나 반응식(`>>`)을 `=SMILES2MW`, `=SMILES2LOGP`, `=SMILES2FSP3` 같은 단일 분자 물성 함수에 전달하면 엉뚱한 숫자 대신 `#N/A`를 반환합니다.
