# Ketcher 2D 구조/반응식 편집기 가이드

Excel, Word, PowerPoint 어디서든 외부 프로그램 없이 분자 구조식과 다단계 유기 합성 반응식을 직접 그릴 수 있는 내장 **Ketcher 2D 화학 편집기** 사용법을 안내합니다.

<p align="center">
  <img src="/ketcher-guide.png" alt="Ketcher 에디터 인터페이스" width="100%" style="border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.12);" />
</p>

::: tip 💡 왜 편할까요?
* **100% 오프라인 작동:** 인터넷 연결 없이 내 PC 안에서만 작동하므로 보안이 중요한 연구실에서도 안심하고 사용할 수 있습니다.
* **기다림 없는 즉시 실행:** 한 번 연 뒤에는 백그라운드에 준비 상태로 대기하여, 더블클릭할 때마다 **0.05초 만에** 즉시 열립니다.
* **실시간 분자량·화학식 표시:** 원자와 결합을 그리는 즉시 상단 바에 **화학식(Formula), 분자량(MW), 정밀 질량(Exact Mass)**이 자동으로 계산됩니다.
:::

## 1. 3단계로 그리기 & 수정하기

<p align="center">
  <img src="/workflow-ketcher.png" alt="Ketcher 작업 흐름" width="100%" style="border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.12);" />
</p>

### Step 1. 편집기 열기
* **새로 그리기:** 키보드에서 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>를 누르거나, 상단 **`[SMILES] ➔ [구조식 삽입]`**을 클릭합니다.
* **기존 분자 고치기:** 엑셀 셀이나 워드·파워포인트에 들어간 분자 그림을 **마우스로 더블클릭**합니다.

### Step 2. 분자 및 합성 반응식 스케치
* **결합 & 고리 템플릿 (좌측 도구 모음):** 단일·이중·삼중 결합, 입체 결합(쐐기/점선), 벤젠·사이클로헥산 등 자주 쓰는 고리를 클릭해 배치합니다.
* **원자 선택 (우측 도구 모음):** `C`, `N`, `O`, `S`, `P`, 할로겐 원소 및 주기율표 전체 원소를 선택합니다.
* **화학 반응식 그리기:** 화살표 도구(`➔`)와 플러스(`+`), 텍스트(`T`) 도구를 사용해 시약($H_2SO_4$), 온도(55 °C), 수율 등이 포함된 전체 반응 경로를 그릴 수 있습니다.

### Step 3. 배경 선택 후 문서에 반영 (`Ctrl + Enter`)
* 상단 바에서 **`[배경: 흰색]`** (일반 문서/시트용) 또는 **`[배경: 투명]`** (다크 모드 슬라이드/색상 셀용)을 선택합니다.
* <kbd>Ctrl</kbd> + <kbd>Enter</kbd> (또는 우측 하단 **Apply** 버튼)를 누르면 문서나 셀에 고해상도 구조식이 즉시 들어갑니다!

## 2. 필수 단축키 모음

| 단축키 / 조작 | 기능 | 설명 |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | **편집기 열기** | 현재 선택한 셀이나 커서 위치에 새 구조식 그리기 |
| **마우스 더블클릭** | **제자리 수정** | 이미 삽입된 분자나 반응식을 다시 열어 바로 수정하기 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | **문서에 적용 (Apply)** | 그린 내용을 문서/셀에 즉시 반영하고 창 닫기 |
| <kbd>Esc</kbd> | **취소** | 변경 사항을 반영하지 않고 편집기 닫기 |
