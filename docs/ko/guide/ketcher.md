# Ketcher 2D 화학 분자 & 반응식 에디터 가이드

**SMILES for Microsoft Office Suite**는 Microsoft Edge WebView2를 통해 로컬 오프라인으로 구동되는 **EPAM Ketcher v3.18.0** 2D 화학 에디터를 내장하고 있습니다.

---

## 🌟 주요 기능 및 특징

<p align="center">
  <img src="/ketcher-guide.png" alt="Ketcher 에디터 인터페이스" width="100%" style="border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.12);" />
</p>

* **100% 로컬 오프라인 보안:** 외부 인터넷 연결이나 클라우드 전송 없이 내 컴퓨터 안에서 안전하게 실행됩니다. 연구 기밀 화합물도 완벽히 보호됩니다.
* **초고속 즉시 실행 (`<0.05초` Warm Pooling):** 싱글톤 WebView2 에디터 인스턴스를 메모리에 상주시키고 창을 닫을 때 프로세스를 종료하는 대신 숨김(Hide) 처리하여, 두 번째 실행 및 더블클릭 재편집 시 **0.05초 미만**으로 즉시 열립니다.
* **전문 화학 구조 그리기:** 단일·이중·삼중·방향족 결합, 쐐기/점선 입체화학 결합(Wedge/Hash), 주기율표 전체 원소, 벤젠/사이클로펜탄 등 고리 템플릿.
* **유기화학 반응식(Reaction Scheme) 지원:** 반응 화살표, 플러스 기호(+), 촉매 및 반응 조건 텍스트 주석을 자유롭게 배치할 수 있습니다.
* **실시간 분자 물성 계산:** 구조식을 그리는 즉시 화학식(Formula), 분자량(MW, g/mol), 정밀 질량(Exact Mass)이 상단 상태 바에 실시간 계산됩니다.

## 🔬 다단계 화학 반응식 & 합성 경로: `=KET2IMG`

반응물, 반응 화살표, 시약, 촉매, 최종 생성물이 모두 포함된 유기 합성 반응식을 손쉽게 그릴 수 있습니다:

* **무손실 좌표 및 텍스트 보존:** Ketcher 고유의 `KET` 포맷은 반응 화살표, 촉매 조건 텍스트($H_2SO_4$, 55 °C), 2D 공간 좌표 레이아웃을 100% 무손실 상태로 보존합니다.
* **더블 클릭 제자리 수정:** 반응식 셀이나 이미지를 더블 클릭하면 `<0.05초` 만에 Ketcher에 반응 화살표와 텍스트 주석이 그대로 다시 열려 언제든 조건이나 반응물을 제자리에서 수정할 수 있습니다.

## ⌨️ 핵심 단축키 안내

| 단축키 | 동작 | 설명 |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | **에디터 실행 (Excel)** | 현재 선택된 셀의 구조식을 즉시 Ketcher에서 편집 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | **문서에 적용** | 그린 구조식을 문서/셀에 즉시 삽입하고 에디터 창 닫기 |

| **더블 클릭** | **제자리 수정** | 엑셀 셀이나 워드/파워포인트 그림을 마우스로 더블 클릭 |

## 🎨 작업 흐름 & 투명 배경 설정

<p align="center">
  <img src="/workflow-ketcher.png" alt="Ketcher 작업 흐름" width="100%" style="border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.12);" />
</p>

### 1. Ketcher 실행 방법
* **Excel:** 셀을 선택하고 단축키 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>를 누르거나, 우클릭 ➔ **Chemical Structure ➔ Edit Structure in Ketcher**를 선택합니다.
* **Word / PowerPoint:** 상단 리본 `[SMILES]` 탭에서 **[Insert Structure]**를 누르거나 기존 그림을 더블 클릭합니다.

### 2. 분자 및 반응식 그리기
* 왼쪽 툴바에서 결합 종류 및 템플릿(벤젠환, 고리 화합물 등)을 선택합니다.
* 오른쪽 원소 툴바에서 원하는 원자 기호를 클릭합니다.
* 유기 합성 반응식을 그릴 때는 왼쪽 하단 반응 도구(화살표, 플러스 기호)를 활용합니다.

### 3. 투명 배경 토글
Ketcher 상단 상태 바에서:
* **[배경: 흰색]:** 일반적인 흰색 문서, 인쇄용 논문, 기본 엑셀 시트에 적합합니다.
* **[배경: 투명]:** 알파 채널 투명 배경으로 내보내어, 파워포인트 다크 테마나 유색 배경 셀에서도 테두리 없이 깔끔하게 표시됩니다.

### 4. 문서에 적용
<kbd>Ctrl</kbd> + <kbd>Enter</kbd> (또는 **[적용]** 버튼)를 누르면 로컬 EPAM Indigo 렌더러가 즉시 고해상도 이미지를 생성하여 문서에 배치합니다.
