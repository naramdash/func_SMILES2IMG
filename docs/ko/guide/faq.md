# 자주 묻는 질문 (FAQ) 및 문제 해결

**SMILES for Microsoft Office Suite** 사용 중 자주 발생하는 질문과 오류 해결 방법입니다.

---

## ❓ 엑셀 및 수식 관련 질문

### Q. 내 엑셀 버전에서는 어떤 수식을 사용해야 하나요?
* **Microsoft 365 또는 Excel 2024 이상:** `=SMILES2IMG(...)` 수식을 사용하세요. 셀 안에 실제 인셀(In-Cell) 그림으로 삽입되어 셀 크기에 맞춰 자동 연동됩니다.
* **Excel 2016, 2019, 2021:** `=SMILES2IMG.FLOAT(...)` 수식을 사용하세요. 구버전 엑셀에는 인셀 이미지 엔진이 없으므로, 셀 위에 위치하는 플로팅 도형으로 생성됩니다. 셀 이동 및 크기 변경 시 함께 이동합니다(`xlMoveAndSize`).

### Q. 수식이 `#VALUE!` 오류를 반환합니다. 원인을 어떻게 확인하나요?
1. 참조한 셀에 올바른 SMILES 문자열이 들어있는지 확인하세요.
2. 병합된 셀(Merged cells)을 참조하는 경우, 실제 값이 들어있는 좌상단 셀 좌표를 가리키고 있는지 확인하세요.
3. **정확한 화학 오류 확인하기:** 엑셀 상단 리본 메뉴에서 **[SMILES] ➔ [Show diagnostics]**를 클릭하세요. 닫히지 않은 고리(`cycle not closed`), 비정상 원자가(valence error), 미인식 원자 등 화학 파서 오류와 위치가 로그 창에 정확히 출력됩니다!

### Q. 분자 그림 크기가 너무 작게 표시됩니다.
이미지는 셀 영역 안에서 왜곡 없이 비율을 유지하도록 자동 조정됩니다. 셀의 **행 높이(예: 80~120 pt)**와 **열 너비(예: 25~40)**를 늘려주시면 구조식이 선명하고 큼직하게 렌더링됩니다.

### Q. 흑백 논문이나 다크 모드 시트에 색상을 맞추려면 어떻게 하나요?
* **흑백 선화 (특허/ACS 논문):** 3번째 옵션 인수에 `"bw"`를 입력합니다 (`=SMILES2IMG(A2, "", "bw")`).
* **다크 모드:** 2번째 인수에 어두운 배경색(`"#1a1a1a"`), 3번째 인수에 흰색 잉크(`"white"`)를 지정합니다:
  ```text
  =SMILES2IMG(A2, "#1a1a1a", "white")
  ```

## 🛡️ 보안 및 실행 관련 문제

### Q. [스마트 앱 컨트롤] "파일 형식과 확장명이 일치하지 않습니다" 경고가 뜨거나 `#NAME?` 오류가 발생합니다.
* **원인:** Windows 11 **스마트 앱 컨트롤(Smart App Control, SAC)**이 강제 적용 모드일 때 서명되지 않은 오픈소스 XLL 추가 기능 바이너리를 차단하여 발생합니다.
* **안심하세요:** 스마트 앱 컨트롤을 꺼도 **Microsoft Defender 실시간 바이러스 백신 감시는 100% 정상 작동**합니다.
* **10초 해결법:**
  1. Windows **설정** (`Win + I`) ➔ **개인 정보 및 보안** ➔ **Windows 보안**으로 이동합니다.
  2. **앱 및 브라우저 컨트롤** ➔ **스마트 앱 컨트롤 설정**을 클릭합니다.
  3. 설정을 **'꺼짐'**으로 변경한 후 Excel을 다시 시작합니다.

### Q. 엑셀이 XLL 추가 기능 로딩을 차단합니다.
웹에서 다운로드한 파일은 Windows 보안 정책에 의해 `Zone.Identifier` 차단 플래그가 붙습니다. `.xll` 파일을 우클릭 ➔ **속성** ➔ 하단 **[차단 해제(Unblock)]**를 체크하고 **[확인]**을 누릅니다.  
또는 보안 차단 해제가 자동으로 포함된 [원클릭 빠른 설치](../guide/getting-started) 명령어를 이용하세요.
