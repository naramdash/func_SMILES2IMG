# SMILES for Microsoft PowerPoint 가이드

**SMILES for Microsoft PowerPoint**는 학회 발표, 연구 세미나, 강의 슬라이드에 2D 화학 구조식을 원클릭으로 배치하고, 다크 테마를 위한 투명 배경 및 더블 클릭 제자리 수정을 지원하는 추가 기능입니다.

::: tip PowerPoint 슬라이드 제작 핵심 장점
* **다크 테마 투명 배경 지원:** 흰색 사각형 테두리 없이 깔끔한 알파 채널 투명 배경으로 렌더링되어 다크 모드 슬라이드 템플릿에 자연스럽게 녹아듭니다.
* **위치 및 비율 완벽 보존:** 슬라이드 위 분자 그림을 더블 클릭하여 수정해도 기존 위치(`Left`, `Top`)와 중심축, 비율이 흐트러지지 않습니다.
* **무손실 슬라이드 보존:** 파워포인트 도형 내부 `Shape.Tags['KET']`와 `Shape.Tags['SMILES']`에 원본 구조식이 영구 저장됩니다.
:::

## 📑 리본 메뉴: `[SMILES]` 탭

1. **구조식 삽입 (Insert Structure):** Ketcher 에디터에서 구조식을 그리고 적용을 누르면 활성 슬라이드 정중앙에 고해상도 그림으로 자동 배치됩니다.
2. **퀵 인서트 (Quick Insert):**
   - 슬라이드의 텍스트 상자나 개체를 선택한 상태에서 누르면 SMILES 텍스트가 즉시 분자 도형으로 치환됩니다.
   - 선택된 개체가 없으면 클립보드의 SMILES를 슬라이드 중앙에 삽입합니다.
3. **클립보드에서 붙여넣기:** 클립보드 내용을 파워포인트 슬라이드에 즉시 붙여넣습니다.
4. **진단 및 로그:** 엔진 로딩 및 추가 기능 진단 정보를 확인합니다.

## 🌓 다크 테마 & 투명 배경 토글

1. Ketcher 에디터 창 상단 상태 바에서 **[배경: 흰색]** 또는 **[배경: 투명]** 버튼을 클릭하여 전환할 수 있습니다.
2. 투명 배경 모드로 설정하면 알파 채널이 적용된 PNG로 슬라이드에 삽입되어 어두운 그라디언트나 컬러 배경 위에서도 결합선과 원자만 깔끔하게 보입니다.

---

## 🖱️ 마우스 더블 클릭 제자리 수정

1. 슬라이드 위에 놓인 화학 분자 도형을 마우스로 더블 클릭합니다.
2. 원본 구조식이 내장 Ketcher 에디터에 즉시 로드됩니다.
3. 원자나 작용기를 수정한 뒤 <kbd>Ctrl</kbd> + <kbd>Enter</kbd> (적용)를 누릅니다.
4. 슬라이드 위 기존 위치와 크기 비율을 유지한 채 그림이 그 자리에서 즉시 업데이트됩니다.

## 📋 우클릭 메뉴 & 세미나 Q&A 대응

발표 슬라이드 제작 중이거나 질문 답변 중 분자 도형을 우클릭:

* **Chemical Structure ➔ 분자량(MW) 복사:** g/mol 분자량 즉시 산출.
* **Chemical Structure ➔ 분자식(Formula) 복사:** Hill 체계 화학식 복사.
* **Chemical Structure ➔ SMILES / KET 복사:** 순수 문자열 복사.
