# Mol* 3D 고분자/단백질 뷰어 (Excel, Word & PowerPoint)

**SMILES for Microsoft Office Suite**에는 Microsoft Edge WebView2 기반의 공식 **Mol\* 3D 고분자/단백질 뷰어 (v5.13.1)**가 100% 완전 오프라인으로 내장되어 있습니다.

---

## 🌟 개요 및 주요 특징

Mol\* (발음: *"몰스타"*)는 최신 생물학 고분자, 단백질 3차 구조, 핵산, 리간드 복합체를 시각화하기 위한 현대 표준 오픈소스 분자 뷰어입니다.

* **100% 로컬 & 오프라인 구동:** 번들 파일 전체가 오피스 애드인 내에 탑재되어 있어 외부 클라우드 접속 없이 로컬 GPU 하드웨어 가속(WebGL)으로 부드럽게 렌더링됩니다.
* **두 가지 삽입 모드 지원:**
  * **인터랙티브 3D 모델 (`.glb`):** 파워포인트 슬라이드, 워드 본문, 엑셀 워크시트에 마우스로 직접 회전/확대할 수 있는 실제 3D 모델로 삽입합니다.
  * **출판용 고해상도 2D 이미지 (`.png`):** 논문 인쇄, 보고서, 엑셀 데이터 분석용 투명 배경 고해상도 그래픽으로 삽입합니다.
* **더블클릭 즉시 재편집 (In-Place Re-editing):** 시트나 슬라이드에 삽입된 3D 모델이나 이미지를 마우스로 더블클릭하면 작업하던 카메라 앵글, 확대 비율, 스타일 그대로 Mol\* 뷰어가 즉시 다시 열립니다.
* **CustomXMLParts 영구 세션 보존:** 작업 세션 레시피(`.molj`)를 통합 문서/프레젠테이션/문서 자체의 `CustomXMLParts`에 자동 압축 보관하므로, 파일을 다른 PC로 전송해도 세션이 100% 완벽하게 복원됩니다.

## 🚀 Mol* 기본 사용법

### 1. 뷰어 실행하기
* **리본 메뉴:** 엑셀, 파워포인트, 워드의 **`[SMILES]`** 리본 탭에서 **`[3D Structure (Mol*)]`** 버튼을 클릭합니다.
* **우클릭 컨텍스트 메뉴:** 슬라이드 빈 공간, 워드 본문, 또는 엑셀 셀을 우클릭한 후 **`3D Structure (Mol*)...`**를 선택합니다.
* **엑셀 스마트 PDB 감지:** 활성화된 엑셀 셀에 4자리 PDB ID(예: `1CRN`, `4HHB`)나 파일 경로가 적혀 있다면, Mol\*을 열었을 때 해당 구조를 자동으로 즉시 불러옵니다!

### 2. 분자 구조 불러오기
뷰어 창 상단에서 손쉽게 구조를 가져올 수 있습니다:
* **RCSB PDB ID 직접 다운로드:** 4자리 PDB 코드(예: `1CRN` 크람빈, `4HHB` 헤모글로빈, `7BWY` 코로나 스파이크 단백질)를 입력하고 **Download PDB**를 클릭합니다.
* **로컬 파일 열기:** PC에 저장된 `.pdb`, `.cif`, `.bcif`, `.sdf`, `.mol`, `.mol2` 파일을 직접 불러옵니다.
* **기존 세션 열기:** 저장해 둔 `.molj` / `.molx` Mol\* 세션 레시피를 열어 작업을 이어갑니다.

### 3. 시각화 스타일 설정
뷰어 우측/상단 컨트롤을 통해 다양한 형태로 표현할 수 있습니다:
* **Cartoon / Ribbon (카툰):** 2차 구조($\alpha$-나선, $\beta$-시트, 루프)를 한눈에 파악.
* **Ball & Stick / Surface (표면):** 결합 포켓, 활성 부위 아미노산 잔기, 보조 인자(Ligand)를 정밀 분석.
* **색상 팔레트:** 사슬(Chain), 2차 구조, 잔기 종류, B-factor(유연성)별 자동 배색.

## 📦 문서 삽입: 3D 모델 vs 2D 이미지

Mol\* 상단 도구 모음에서 목적에 맞는 삽입 모드를 선택합니다:

### 모드 A: [3D Model (.glb)] (인터랙티브 3D)
1. 현재 시점의 카메라 앵글과 표현 스타일을 바이너리 GLTF(`.glb`) 3D 객체로 변환합니다.
2. 파워포인트 슬라이드, 워드 본문, 또는 엑셀 시트(선택 셀 기준 `xlMoveAndSize` 배치)에 네이티브 3D 모델로 즉시 배치됩니다.
3. **인터랙티브 360도 조작 (PowerPoint & Excel):**
   - 슬라이드 편집 모드, 슬라이드 쇼 발표 중, 또는 **엑셀 워크시트 위에서** 모델 중앙의 3D 조작 핸들을 마우스로 드래그하여 청중과 동료 앞에서 단백질을 360도 자유롭게 회전하고 확대하며 설명할 수 있습니다!

### 모드 B: [2D Picture (.png)] (출판 및 보고서 품질)
1. 현재 뷰포트를 고해상도 PNG 이미지로 렌더링합니다.
2. **투명 배경(Transparent)** 옵션을 선택하면 어두운 발표 슬라이드나 표 배경색 위에서도 흰 사각형 테두리 없이 깔끔하게 합성됩니다.

## 🔄 더블클릭 재편집 워크플로

1. 엑셀, 파워포인트, 워드에 삽입된 Mol\* 3D 모델 또는 이미지를 선택합니다.
2. 마우스로 **더블클릭**합니다 (또는 우클릭 ➔ **`Edit 3D Structure (Mol*)...`**).
3. Mol\* 편집기가 즉시 열리며, 기존에 설정했던 단백질 구조, 색상, 확대 비율, 카메라 각도가 그대로 복원됩니다.
4. 원하는 각도로 미세 조정한 뒤 **Apply**를 누르면 위치와 크기를 유지하면서 문서의 내용이 제자리에서 즉시 갱신됩니다.
