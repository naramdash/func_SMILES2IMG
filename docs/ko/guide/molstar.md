# Mol* 3D 단백질 뷰어 가이드

Excel, Word, PowerPoint 안에서 단백질 3차 구조, 핵산, 리간드 복합체를 불러와 시각화하고, 마우스로 360° 돌려볼 수 있는 3D 모델이나 고해상도 이미지로 삽입하는 방법을 안내합니다.

::: tip 💡 Mol* ("몰스타") 3D 뷰어 핵심 특징
* **PDB 코드 4자리로 즉시 불러오기:** `1CRN`, `4HHB`, `7BWY` 같은 PDB ID만 입력하면 구조를 바로 다운로드해 보여줍니다 (로컬 `.pdb`, `.cif`, `.sdf` 파일 열기도 지원).
* **발표 중 마우스로 돌려보는 실제 3D 모델 (`.glb`):** 정적인 캡처 사진 대신 파워포인트 슬라이드나 엑셀 시트 위에서 360° 회전·확대할 수 있는 진짜 3D 객체를 넣을 수 있습니다.
* **더블클릭으로 언제든 재편집:** 문서에 넣은 3D 모델이나 그림을 **더블클릭**하면 마지막에 맞췄던 카메라 각도와 색상 스타일 그대로 다시 열립니다 (다른 PC로 파일을 보내도 그대로 유지됩니다!).
:::

---

## 1. 3단계로 3D 단백질 구조 넣기

### Step 1. Mol* 뷰어 열기
* 상단 **`[SMILES]`** 리본 탭에서 **`[3D 구조식 (Mol*)]`** 버튼을 클릭합니다 (또는 우클릭 ➔ **`Chemical Structure ➔ 3D Structure (Mol*)...`**).
* 💡 **엑셀 꿀팁:** 엑셀 셀에 `1CRN`이나 `4HHB` 같은 4자리 PDB 코드가 적혀 있는 상태에서 버튼을 누르면, 입력할 필요 없이 해당 단백질을 자동으로 즉시 불러옵니다!

### Step 2. 구조 불러오기 & 스타일 꾸미기
1. 상단 입력창에 **4자리 PDB ID**를 입력하고 **Download PDB**를 누르거나, **Open File**로 내 PC의 구조 파일(`.pdb`, `.cif`, `.bcif`, `.sdf`, `.mol`, `.mol2`)을 엽니다.
2. 원하는 표현 방식을 선택합니다:
   * **Cartoon / Ribbon:** α-나선과 β-시트 등 단백질 2차 구조를 한눈에 표현
   * **Ball & Stick / Surface:** 리간드 결합 부위(Binding pocket)와 활성 잔기 분석
   * **배색 변경:** 사슬(Chain)별, 2차 구조별, 아미노산 잔기 특성별 색상 지정

### Step 3. 문서에 삽입하기 (3D 모델 vs 2D 이미지)
창 상단에서 목적에 맞는 삽입 버튼을 누릅니다:

| 삽입 방식 | 특징 및 추천 용도 |
| :--- | :--- |
| **🧊 [3D Model (.glb)]** | 슬라이드 쇼 발표 중이나 엑셀·워드 화면에서 **마우스로 드래그해 360° 자유롭게 돌려볼 수 있는 인터랙티브 3D 모델**로 삽입합니다. |
| **🖼️ [2D Picture (.png)]** | 논문 인쇄, PDF 제출, 보고서 작성을 위한 **고해상도 2D 이미지**로 삽입합니다 (**투명 배경** 선택 시 다크 모드 슬라이드에도 깔끔하게 어우러집니다). |

---

## 2. 바로 입력해 볼 수 있는 추천 PDB 코드 4선

처음 테스트할 때 아래 4자리 코드를 입력해 보세요:

| PDB 코드 | 생체분자 이름 | 관찰 포인트 & 추천 용도 |
| :---: | :--- | :--- |
| **`1CRN`** | **크람빈 (Crambin)** | 작고 깔끔한 소형 단백질 — α-나선과 β-시트 기본 렌더링 테스트용 |
| **`4HHB`** | **인간 헤모글로빈 (Hemoglobin)** | 4개의 사슬(α₂β₂)과 헴(Heme) 보결분자단 복합체 시각화 |
| **`6LU7`** | **SARS-CoV-2 메인 프로테아제 (Mpro)** | 단백질 결합 포켓 내부에 저분자 저해제(N3 리간드)가 결합한 신약 개발 예시 |
| **`1BNA`** | **B-DNA 이중 나선 (Dodecamer)** | 염기쌍 수소 결합과 DNA 이중 나선 골격 구조 시각화 |

---

## 3. 더블클릭으로 각도 및 스타일 다시 수정하기

1. Excel, Word, PowerPoint에 삽입된 3D 단백질 모델이나 2D 그림을 선택합니다.
2. 마우스로 **더블클릭**합니다 (또는 우클릭 ➔ **`Edit 3D Structure (Mol*)...`**).
3. 이전에 작업하던 단백질 구조와 카메라 앵글, 색상 설정이 그대로 복원되어 열립니다.
4. 각도를 살짝 바꾸거나 스타일을 수정한 뒤 **Apply**를 누르면 문서 내 기존 위치와 크기를 유지한 채 제자리에서 바로 업데이트됩니다!
