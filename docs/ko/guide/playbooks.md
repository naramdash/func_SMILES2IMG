# 예제 파일 (Playbooks)

Microsoft Excel, Word, PowerPoint용 **자체 완결형(Self-Contained) 공식 Playbook**을 내려받아 바로 실습해 보세요. 각 파일 안에 핵심 기능 설명, 실제 메타데이터가 담긴 더블클릭 편집 구조식, 실전 화학 템플릿이 모두 들어 있어 웹 문서를 함께 열지 않아도 오피스 안에서 바로 익힐 수 있습니다.

::: tip Playbook 활용 방법
1. 먼저 `func_SMILES2IMG`를 설치합니다 ([설치 가이드](/ko/guide/install)).
2. 위에서 사용할 오피스 앱 카드를 선택해 Playbook을 미리 보고 내려받은 뒤, **Excel**, **Word**, **PowerPoint**에서 바로 엽니다.
3. 파일 안의 실습 박스를 따라 SMILES 입력을 바꾸거나, 임베드된 구조식·반응식을 더블클릭해 **Ketcher 2D** / **Mol\* 3D** 편집과 원클릭 **`Batch Style`** 전환을 직접 체험해 보세요.
:::
